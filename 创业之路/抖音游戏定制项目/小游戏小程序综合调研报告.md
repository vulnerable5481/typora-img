## 1.3 开发成本

- **服务器**

  - 物理机：暂不考虑
  - 轻量级云服务器
    - 2核2G40G3M带宽---200~300一年
    - 新号薅羊毛，偶尔能捡漏，可以搞到4核4G的服务器，一般为99/199一年，续费恢复原价
  - 大前端开发：轻量级服务器甚至不考虑搭建服务器，只靠前端做出单机游戏

  ```
  以打怪游戏为例子：
  1、几乎纯单机：服务器要求极低
  比如玩家进入游戏后：
      打怪、掉血、升级都在手机本地计算；
      地图、怪物、装备配置包含在游戏包里；
      本地保存游戏进度；
      服务器只负责登录、排行榜、广告奖励校验和云存档。
  【这种游戏即使有几百名玩家同时在线，后端压力也可能不大。只有加载/上传数据的时候会与服务器发生交互，买个便宜服务器够用了】
  
  2、弱联网游戏：服务器要求中等
   参考赛尔号那种，要求的服务器响应实时性没那么高；饥荒、MC这种其实也还好
  
  3、联网游戏：服务器要求高
  【不在考虑范围内】
  
  【总结一下：建议做单机游戏，尤其是在缺少游戏开发经验前提下，如果是我们自己搭建个游戏服务器，就几个朋友开黑玩玩那其实很简单也便宜，但是如果我们正儿八经地做游戏，那肯定不够用】
  ```

- **审核成本**

# 6、名词解释

- ICP备案、ICP证

  - ICP备案相当于互联网服务的“登记信息”；ICP许可证相当于经营性互联网服务的“经营许可”。

  | 项目                 | ICP备案                  | ICP许可证            |
  | -------------------- | ------------------------ | -------------------- |
  | 性质                 | 登记备案                 | 行政经营许可         |
  | 适用情况             | 通常是非经营性互联网服务 | 经营性互联网信息服务 |
  | 办理难度             | 相对简单                 | 明显更高             |
  | 是否等于可以收费经营 | 不是                     | 在许可业务范围内可以 |
  | 常见编号             | 粤ICP备……号              | 粤B2-……号            |

# 7、资质申请

- ⚠️**版号申请**
  - 版号申请需要经过严格的审核，周期通常为6-12个月，费用为5-20万元。
- **⚠️ICP证**
  - ICP备案（不超过20个工作日）
  - ICP证（30~60个工作日）
    - 企业法人营业执照副本。
    - 法定代表人及股东身份证。
    - 公司主要管理人员及技术人员身份证。
    - 社保证明。
    - 接入协议及托管商资质。
    - 域名注册证书。

- ⚠️**软件著作权证书（2~3月）**
  - 完成阶段：整理软著文件，根据软件内容量不定，预计3~7天
  - 受理阶段：提交材料后 **1-2周内** 收到受理通知书
  - 审查阶段：自软著受理日起 **60日内** 完成审查（官方法定时限）
  - 修正阶段：✅理想情况无需修改；⚠️ 补正风险期：每次补正增加 **2-4周。**
