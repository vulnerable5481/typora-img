# 一、半导体全工艺流程

## 1、前道晶圆制造（Fab 厂）

### 1.1、工艺场景与流程

①  **Wafer 入厂：**

→ **薄膜沉积**：往晶圆上面加材料
 → **光刻 ADI / OP**：通过光刻，把晶圆的电路图形做出来
 → **蚀刻 AEI**：按照图形把材料刻掉
 → **离子注入**：改变局部电学性质
 → **清洗 / 去胶**：清除残留物
 → **CMP**：把表面磨平
 → 上面的过程根据芯片结构**反复很多次**
 → **EBI / 各类检测**
 → **Wafer 出厂终检**

②  **ADC软件/AI算法包：**

检测设备发现异常 → 产生缺陷图像 → ADC/AI 获取图像 → 模型推理 → 缺陷分类/定级 → 结果回到检测或生产系统。

### 1.2、工艺场景表

| **工艺段**                                             | 操作                                                         | **AI/ADC算法 接入场景**                             |
| ------------------------------------------------------ | ------------------------------------------------------------ | --------------------------------------------------- |
| 晶圆入厂检验                                           | 晶圆进入 Fab 厂以后，先检查晶圆本身有没有问题                | 原生缺陷自动分类（颗粒、划痕、位错、翘曲）          |
| 薄膜沉积后检测                                         | 晶圆制造不是一次把电路做出来，而是不断进行“**沉积 → 光刻 → 蚀刻 → 注入 → 清洗 → 再沉积……**”这样的循环。<br />第一步，沉积：在晶圆表面铺上一层非常薄的材料，沉积完以后，就要检查这一层膜有没有异常。 | 薄膜缺陷分类（针孔、剥落、厚度不均、污染）          |
| 光刻显影后检测（ADI）<br>光学光刻Optical Process（OP） | 把电路图形通过光刻的方式“转移”到晶圆上。<br />Mask / 光罩 → 曝光 → 显影 → 在晶圆表面形成图形。 | 光刻图形缺陷分类（涂胶异常、断线 / 桥接、套刻偏移） |
| 蚀刻后检测（AEI）                                      | 光刻得到电路图案后，下一步通常利用图案把不需要的材料‘刻掉。光刻负责“画图”，蚀刻负责按照这个图真正把结构做出来 | 蚀刻缺陷分类（过刻 / 欠刻、胶残留、图形变形）       |
| 离子注入后检测                                         | 改变晶圆局部区域的电气特性：往晶圆指定区域“打入”特定离子，让这个区域获得需要的电学性质 | 注入损伤、胶残留、颗粒缺陷分类                      |
| 清洗 / 去胶后检测                                      | 前面的光刻、蚀刻等步骤会用到光刻胶，也可能带来污染物，所以需要反复进行清洗、去胶。但清洗之后可能依然存在缺陷。 | 胶残留、颗粒、腐蚀损伤缺陷分类                      |
| 化学机械抛光（CMP）后检测                              | 抛光：把晶圆表面重新“磨平”<br />因为前面不断沉积、刻蚀之后，晶圆表面会越来越不平。如果不处理，后面继续做下一层电路时就会出问题 | 抛光缺陷分类（划痕、碟形凹陷、侵蚀、粗糙度异常）    |
| 电子束检测（EBI）                                      | 普通光学检测受到光学分辨率限制，有些非常小的缺陷不容易看到。电子束检测主要针对纳米级的微观缺陷。 | 纳米级微观缺陷自动分类（先进制程核心场景）          |
| 晶圆出厂终检                                           | 前道 Fab 的最后一个阶段，经历这么多工艺以后，要对整片 Wafer 做最终质量判断 | 全流程缺陷定级、良品分级                            |

## 2、中道晶圆级封装

### 2.1、工艺场景与流程

```
前道工艺主要关注“电路有没有做对”；
中道开始更多关注“芯片怎么被连接、怎么被切分、怎么进入封装”
晶圆已经从“前道做电路”逐步进入“把晶圆加工成可封装、可互连、可分割的器件”
```

**中道晶圆级封装**

→ **Wafer 减薄**
 → **Wafer 切割 / Die 分离**
 → **RDL 重布线**
 → **Bumping 凸点制作**
 → **晶圆级封装终检**

### 2.2、工艺场景表

| **工艺段**              | 操作                                                         | **AI/ADC 接入场景**                     |
| ----------------------- | ------------------------------------------------------------ | --------------------------------------- |
| 晶圆减薄后检测          | 晶圆做完前道工艺后，通常还是比较厚的。中道封装阶段会对晶圆背面进行研磨，把 Wafer 做薄。 | 研磨划痕、裂纹、翘曲、颗粒缺陷分类      |
| 晶圆切割后检测          | 前面整片 Wafer 上其实已经做了很多颗芯片，沿着芯片之间预留的切割道走，把die从wafer中切割下来。<br />Wafer 级 → Die 级 | 切割崩边、裂纹、碎屑、刀痕偏移缺陷分类  |
| 重布线层（RDL）检测     | 重新把芯片原来的电气连接点“引出来并重新排布”<br />比如芯片原来的 Pad 位置不适合直接做后面的焊球，那么就通过 RDL 做一层新的金属线路，把信号重新引到更合适的位置 | 布线开路 / 短路、线宽异常、颗粒缺陷分类 |
| 凸点制作（Bumping）检测 | 在芯片的连接位置上做一个个凸点，用于后续电气连接<br />● ● ● ●：这一颗颗的点就是 Bump，可能出现缺失，偏移等缺陷 | 凸点缺失、偏移、桥接、高度不均缺陷分类  |
| 晶圆级封装终检          | 这些相关加工完成以后，还要做一次整体外观终检                 | 晶圆级成品外观缺陷全检分类              |

## 3、后道器件封装

### 3.1、工艺场景与流程

```
Die/芯片已经从 Wafer 阶段切割出来后，如何被贴装、连接、塑封、成型，最后做成真正可以使用和出货的封装器件。
前道 Fab：把电路做在 Wafer 上
中道：对 Wafer 做减薄、切割、RDL、Bumping 等处理
后道：把 Die 真正封装成一颗完整器件
```

### 3.2、工艺场景表

| **工艺段**                | 操作                                                         | **AI/ADC 接入场景**                            |
| ------------------------- | ------------------------------------------------------------ | ---------------------------------------------- |
| 芯片贴装后检测            | 把一颗 Die 放到封装基板或引线框架上的指定位置。              | 芯片偏移、倾斜、银浆空洞、破损缺陷分类         |
| 引线键合后检测            | 用很细的金属线，把芯片上的 Pad 和外部引脚/基板连接起来。     | 焊球偏移、金线断裂、虚焊、弧高异常缺陷分类     |
| 塑封成型后检测            | 用封装材料把芯片和内部结构包起来，起到保护作用。             | 塑封空洞、缺料、溢料、划痕、污染缺陷分类       |
| 焊球植入 / 引脚电镀       | 比如 BGA 类封装，需要在芯片底部形成很多焊球<br />● ● ● ● <br />● ● ● ● <br />● ● ● ●<br />可能出现焊球缺失、不均等等缺陷 | 焊球缺失 / 不均、镀层漏镀 / 厚度不均缺陷分类   |
| 激光打标后检测            | 封装完成以后，芯片表面通常会用激光打上标识：产品型号、Lot、日期、厂商信息、二维码 | OCR 内容校验、打标缺陷分类（错印、模糊、偏移） |
| 切筋成型后检测            | 芯片塑封完成以后，原本很多器件可能还连在一起，需要切筋 + 引脚成型，最后形成一个个独立芯片 | 引脚变形、连筋、毛刺、共面度异常缺陷分类       |
| 成品外观终检（Final AOI） | 对成品外观进行一次最终检查                                   | 成品全外观缺陷自动分类                         |
| 编带 / 包装后检测         | 芯片做完以后通常不会一颗颗散着运输，而是放到tray盘等其他包装形式，属于出货前最后一道防线。 | 缺料、反置、混料、批次一致性校验               |

## 4、测试与可靠性

### 4.1、工艺场景与流程

```
这一段就是整条半导体流程里偏“功能验证和质量验证”的部分，
不一定就是测试芯片，也可能发生在晶圆阶段
```

### 4.2、工艺场景表

| **工艺段**         | 操作                                                         | **AI/ADC 接入场景**                    |
| ------------------ | ------------------------------------------------------------ | -------------------------------------- |
| 晶圆探针测试（CP） | 在晶圆还没有完全做成最终封装芯片之前，先测试每一颗 Die 的电性能Wafer --->  Probe Card   ----> 测试每颗 Die | 良率聚类、失效模式分类、探针卡寿命预测 |
| 成品终测（FT）     | 已经封装好的 Chip ---> 测试设备 ----> 成品电性 / 功能测试    | 测试项优化、电性失效模式自动分类       |
| 可靠性测试         | 芯片长期稳定性                                               | 寿命预测、失效模式关联分析             |
