# 1、配置文件

## 1.1 多模块读取配置

```
问题背景：我在SSO模块写了如下的配置，并通过@Value注解调用，多模块运行的时候SSO模块没有报错，但是运行ai-run模块报错了
解决方案：① 最暴力直接把copy到ai-run等每个需要该属性的模块中；
		② 最优雅就是把这些配置属性都放到公共模块下的resources下的配置文件中；
		③ Spring Cloud Config（配置中心）：更常用的就是nacos进行管理公共属性
联想灵感：我记得学习分布式的时候，应该是nacos有接触过，可以统一管理配置属性来着。

// 配置文件
login:
  #密码加密方式：1 简单 2 复杂
  passwordEncryptionType: 1
  #存储密码方式：1明文 2密文 默认明文
  passwordEncryption: 1
  # 加密盐值
  passwordSalt: 2026_salt
// 调用：
    @Value("${login.passwordEncryption}")
    private Integer passwordEncryption;

    @Value("${login.passwordSalt}")
    private String passwordSalt;
```





# 2、GIT

## 2.1 无信息merge

```
场景：我本地有一个或多个已commit但是未push的提交，远程有人提交了，明明代码没有冲突也会出现merge，且merge是无信息的，没有办法解决，只能通过git reset --hard HEAD~1 干掉刚刚的pull从而干掉merge

原因：遇到的现象其实非常典型：本地有未 push 的提交（commit），远端也有人提交了新 commit，这时你执行 git pull，Git 发现 两边分叉了，默认就会走“合并（merge）”路线，于是出现一个 merge commit。

解决：git --rebase  自动汇合两条路线
```
