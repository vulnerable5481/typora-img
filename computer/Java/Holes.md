## 1.参数传递机制



**java要是能直接操纵指针该多好啊！**

```
java的参数永远都是值传递！！！
	只能通过返回值，也就是另开一个地址去接收函数返回的结果，达到伪修改的效果，实际上原地址存储的数据没有改变，
	int change(int x){return 1;}   int res = change(0);
	【但是对于引用传递，比如对象，可以在函数里面修改对象的属性，但不能】
 	
C++|C的参数默认是值传递，但是指针！！
	void change(int x){ x = 1;}  // 这样是值传递，外部变量不会修改
	void change(int* x) {*x = 1;} // 这样通过指针去修改对应的变量，当然能修改外部变量了
	.java -> .class字节码文件 
	入门
```
