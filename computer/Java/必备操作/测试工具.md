# Swagger

## 1、导言

```
  Swagger是一个开源的API文档生成工具，可以根据代码生成可交互的API文档，方便自己或其他人更直观地了解和测试你的接口。
  之前我们可能用postman去测试，但是操作比较繁琐，swagger更方便，不过我个人还是喜欢postman
```

## 2、操作教程

```java
// Knife4j是为Java MVC框架集成Swagger生成Api文档的增强解决方案

// knife4j  maven坐标
<dependency>
    <groupId>com.github.xiaoymin</groupId>
    <artifactId>knife4j-spring-boot-starter</artifactId>
</dependency>
```

1. 导入knife4j的maven坐标
2. 在配置类中加入knife4j相关配置
3. 设置静态资源映射，否则接口文档页面无法访问
4. 进行完以上三个步骤就可以 使用url进入swagger提供的一个页面 比如localhost:8080/doc.html，该页面就是swagger主页面

```
/**
 * 配置类，注册web层相关组件
 */
@Configuration
@Slf4j
public class WebMvcConfiguration extends WebMvcConfigurationSupport {
    /**
     * 通过knife4j生成接口文档
     * @return
     */
    @Bean
    public Docket docket() {
        ApiInfo apiInfo = new ApiInfoBuilder()
                .title("xx项目接口文档")
                .version("2.0")
                .description("苍穹外卖项目接口文档")
                .build();
        Docket docket = new Docket(DocumentationType.SWAGGER_2)
                .apiInfo(apiInfo)
                .select()
                //指定生成接口需要扫描的包
                .apis(RequestHandlerSelectors.basePackage("com.sky.controller"))
                .paths(PathSelectors.any())
                .build();
        return docket;
    }

    /**
     * 设置静态资源映射
     * @param registry
     */
    protected void addResourceHandlers(ResourceHandlerRegistry registry) {
        registry.addResourceHandler("/doc.html").addResourceLocations("classpath:/META-INF/resources/");
        registry.addResourceHandler("/webjars/**").addResourceLocations("classpath:/META-INF/resources/webjars/");
    }
}
```

## 3、常用注解

//通过注解可以控制生成的接口文档，是接口文档拥有更好的可读性

| **@Api**              |     **用在类上，例如Controller，标识对类的说明**     |      |
| --------------------- | :--------------------------------------------------: | ---- |
| **@ApiModel**         |           **用在类上，例如entity,dto,vo**            |      |
| **@ApiModelProperty** |             **用在属性上，描述属性信息**             |      |
| **@ApiOperation**     | **用在方法上，例如Controller的方法，说明方法的用途** |      |





# JMeter



## 1、导言

```
  JMeter是一个纯java编写的开源软件，主要用于性能测试与功能测试。它支持Web（Http、Https）等，我们最常使用的是就是Web。
```

## 2、下载

```
https://blog.csdn.net/Zachyy/article/details/139717444
或者自己随便找一下即可
```

## 3、使用

```
1、启动Jmeter:
	① 进入 apache-jmeter-5.6.3/bin 文件夹，点击 jmeter.bat 文件，运行JMeter
	② 在 cmd 中输入 jmeter 指令打开 Jmeter：输入jmeter

2、Jmeter脚本编写：
	这里我们用www.baidu.com为例，进行基本脚本编写
	
2.1 添加线程组：
	右键点击“Test Plan” -> 添加 -> 线程（用户） -> 线程组，可添加测试需要的线程组
	
	参数解释：
		①Ramp-Up时间：虚拟线程数需要多久全部启动。如果线程数为5，准备时长为1 -> 1秒钟启动5个线程，也就是每秒钟启动5个线程。
		②循环次数：如果线程数为100，循环次数10，总共就是1000次请求；若勾选“永久”，一直发起请求，除非停止脚本。
		③Same user on each iteration：每个线程是否使用相同的用户、会话、cookie等
		④调度器：设置线程组启动的开始时间和结束时间(配置调度器时，需勾选循环次数为永远)
		
2.2 添加HTTP请求：
	右键点击线程组 -> 添加 -> 取样器 -> HTTP请求，添加一个HTTP请求
	
	比如对网址 http://www.baidu.com/s?ie=utf-8&wd=jmeter 进行性能测试，根据URL配置数据即可
	参数解释：
		Web服务器：
			①协议：默认是HTTP
			②端口号：默认是80
		HTTP请求：
			①内容编码：默认为ISO-8859-1编码，这里配置为utf-8
		同请求一起发送参数:
			注意如果值有中文需要勾选“编码”

2.3 查看结果树：
	右键点击线程组 -> 添加 -> 监听器 -> 查看结果树，添加一个查看结果树
	
2.4 添加聚合报告：
	右键点击 线程组 -> 添加 -> 监听器 -> 聚合报告，用以存放性能测试报告，如响应时间、吞吐量、错误率等
	
【还有很多丰富的功能，比如断言，用到再说吧！】
```
