## 1、日志定位

```
当我们查看log日志文件的时候，需要快速定位到我们需要的内容，这时我们就可以通过notepad++打开
比如：我们需要从日志中筛选出包含‘解析耗时’和'接口耗时'的行，方便进行性能分析，通过使用匹配和书签功能，高效删除无关行，简化日志内容
需求:只保留带有"解析耗时"和"接口总耗时"的行,删除其他行,方便对比日志

1、ctrl+F直接搜索，也可以使用正则表达式
   标记->勾选‘标记所在行’、‘清除上次标记’、‘循环查找’ -> 查找模式可以是普通or正则
  
2、click工具栏的搜索 -> 书签 -> 删除未标记的行   为了美观这时就可以清除标记了
```
