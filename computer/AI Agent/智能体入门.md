# 1、Agent发展史

## 1.1 初识Agent

```
1、Agent到底是什么？
  标准定义:智能体可以通过传感器(Sensors)感知所处的环境(Environment)，并自主(auto)地通过执行器(Actuators)采取行动(Action)
  三个核心要素： 1、传感器：拥有感知环境能力，比如无人车可以感知复杂的道路环境、代码的上下文
  		       2、执行器：可以是一个机器臂，或者虚拟工具（执行代码、调用工具）
  		       3、自主性： 能够基于其感知和内部状态进行独立决策，以达成其设计目标

2、传统Agent VS LLM
	传统智能体：过去的智能体只具备感知能力和执行能力，但是不具备真正的自主性。
			  比如一个智能的温度调节设备，只是根据环境执行预设方案，并不具备自主性
			  if(temp>n) cold
			  else hot
	大语言模型：Large Language model;LLM; 并非传统的静态范式，拥有自主性。
			  比如一个拥有自主性的温度调节设备，可以根据自主性自动根据环境调节（此处的环境也绝非只是温度，比如可以动态适应用				  户的喜好/地球环境的变化，可以阅读天气预报提前准备，能感知湿度等等更综合的因素，可以选择是开空调还是风扇更节约资                 源）。
		
3、核心区别：
	就一句话，传统的智能体是根据具体的工程进行显示的编程与算法方案构建；LLM则是基于海量数据进行训练与推理，具有自主能力。
```



## 1.2 Agent分类

```
1、符号主义AI（Symbolic AI）
	符号主义AI，就是上述的传统Agent，符号也就是主要优势是推理逻辑是基于一套显示的逻辑，这意味着其推理过程是可以被追溯的。
	这里的符号指的是人类可识别的实体，比如词语、数字、概念等。

2、亚符号主义AI
	亚符号主义，分布在一个由大量神经元组成的复杂网络中，是从海量数据中学习的统计模式。深度学习和神经网络是其代表。
	如果说符号主义也就是传统的Agent是通过一个规则图书馆来进行学习的，比如学习猫的概念是通过一些规则，比如猫有四肢，会捕鱼这样的规则去认识的，而亚符号主义的AI则是通过大量的猫的图片和影像资料自己去学习，在看过成千上万张猫的图片资料后，AI的神经网络能辨识出“猫”这个概念的视觉模式。这意味着能够轻松处理图像、声音等非结构化数据，这在符号主义 AI 看来是极其困难的任务。但是亚符号主义AI虽然能够辨别猫的概念，但基于大量数据的学习，这也意味着可能出现幻觉。

3、神经符号主义
	就是结合了前面两种范式优点的产物，既能像神经网络一样从数据中学习，也能像符号逻辑系统一样进行逻辑推理的混合。
	我们目前经常说的LLM，就是神经符号主义的极佳示例，内核是一个巨大的神经网络，使其具备学习能力，然后在它工作的时候会生产一系列结构化的中间步骤、计划或API调用，这些都是明确的、可操作的符号。
```



## 1.3 Agent发展史

```
1、基于符号与逻辑的古典智能体
	推理符号系统假说（PhysicalSymbol SystemHypothesis, PSSH），核心指的是在一个能够在物理世界存在的系统，它是由一组符号与对符号进行处理的过程组成的，也可以理解为数据与各种公式。简而言之，PSSH认为智能的本质就是对符号的计算与处理。
	古典时期的人工智能主要就是基于PSSH思想，主要代表就是专家系统，核心目标是通过将专家的知识与经验制作成知识库，通过计算机编程让程序能够根据知识库和显示的规则模拟专家进行判断。一个比较典型的专家系统就是MYCIN系统，由斯坦福大学于20世纪70年代开发。它被设计用于辅助医生诊断细菌性血液感染并推荐合适的抗生素治疗方案，主要创新点就是使用置信因子的概念，这样输出的结论就有了一定的可信度。
	缺点：需要基于显示的规则编程、知识库，没有自主学习能力，更像是一个智能程序而非人工智能！

2、基于强化学习的智能体
	其核心目标不再是手动编码知识，或者设计一套自上而下基于一个中心处理器的系统，而是赋予智能学习能力，使其像人类一样学习知识。这种通过与环境互动、根据反馈信号来优化自身行为的学习机制，就是强化学习的核心框架。
	深度学习在21世纪的成功，为智能体赋予了强大的感知和模式识别能力，使其能够直接从原始数据（如图像、声音、文本）中理解世界，这是符号主义时代难以想象的。其次，试错与奖励，比如AlphaGo，会根据当前棋局情况选择最优落点，并根据胜负结果，会收到一个明确的信号：赢了就是正向奖励，输了则是负向奖励。通过数百万次这样的自我对弈，AlphaGo不断调整其内部策略，逐渐学会了在何种棋局下选择何种行动，最有可能导向最终的胜利。这个过程完全是自主的，不依赖于人类棋谱的直接指导。

3、基于大规模数据的预训练
	强化学习赋予了AI自主学习能力，但是在最开始AI如何学习？这通常依赖大规模数据的训练。
	比如工厂里面的缺陷检测
	① 预训练阶段：首先学习大量的原始板、图片，通过自监督学习的方式建立训练一个超大规模的神经网络模型，这个阶段不需要模型能够识别缺陷，而是学习这些板本身的规律、结构、事实知识以及上下文逻辑。
	【自监督学习：就是不断调整算法，逐渐提高模型的正确率，其实就是概率学，在高维空间里拟合概率分布】
	② 微调阶段： 完成预训练后，这个模型已经学习到了和数据集有关的丰富知识，后续针对下游的缺陷识别任务只需要少量缺陷数据对模型进行微调即可让模型能够识别缺陷类型。

4、大语言模型的诞生与新能力
	通过在亿万级别的预训练，大型语言模型的神经网络已经构造了一个能够理解世界的模型，更接近人类的思维。
	新能力：① 上下文学习 ② 思维链，面对复杂的问题，先输出一步步推理过程，最终给出解决方案。
	至此几个核心技术已悉数出现，符号主义提供了逻辑推理框架、神经网络深度学习提供了学习与决策能力、大语言模型则通过预训练获得海量知识和通用推理能力，而现代智能体(2026)将这些能力都融为一体。

5、基于大语言模型的智能体
	以LLM为核心的智能体已经成为人工智能领域的新范式，它不仅能理解和生产人类语言，还能通过与环境的自主交互、感知、规划、决策和执行任务
```
