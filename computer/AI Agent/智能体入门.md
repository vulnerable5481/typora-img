# 1、Agent与模型基础

## 1.1 初识Agent

```
1、Agent到底是什么？
  标准定义:智能体可以通过传感器(Sensors)感知所处的环境(Environment)，并自主(auto)地通过执行器(Actuators)采取行动(Action)
  三个核心要素： 1、传感器：拥有感知环境能力，比如无人车可以感知复杂的道路环境、代码的上下文
  		       2、执行器：可以是一个机器臂，或者虚拟工具（执行代码、调用工具）
  		       3、自主性： 能够基于其感知和内部状态进行独立决策，以达成其设计目标

2、传统Agent VS LLM
	传统智能体：过去的智能体只具备感知能力和执行能力，但是不具备真正的自主性。
			  比如一个智能的温度调节设备，只是根据环境执行预设方案，并不具备自主性
			  if(temp>n) cold
			  else hot
	大语言模型：Large Language model;LLM; 并非传统的静态范式，拥有自主性。
			  比如一个拥有自主性的温度调节设备，可以根据自主性自动根据环境调节（此处的环境也绝非只是温度，比如可以动态适应用				  户的喜好/地球环境的变化，可以阅读天气预报提前准备，能感知湿度等等更综合的因素，可以选择是开空调还是风扇更节约资                 源）。
		
3、核心区别：
	就一句话，传统的智能体是根据具体的工程进行显示的编程与算法方案构建；LLM则是基于海量数据进行训练与推理，具有自主能力。
```



## 1.2 Agent分类

```
1、符号主义AI（Symbolic AI）
	符号主义AI，就是上述的传统Agent，符号也就是主要优势是推理逻辑是基于一套显示的逻辑，这意味着其推理过程是可以被追溯的。
	这里的符号指的是人类可识别的实体，比如词语、数字、概念等。

2、亚符号主义AI
	亚符号主义，分布在一个由大量神经元组成的复杂网络中，是从海量数据中学习的统计模式。深度学习和神经网络是其代表。
	如果说符号主义也就是传统的Agent是通过一个规则图书馆来进行学习的，比如学习猫的概念是通过一些规则，比如猫有四肢，会捕鱼这样的规则去认识的，而亚符号主义的AI则是通过大量的猫的图片和影像资料自己去学习，在看过成千上万张猫的图片资料后，AI的神经网络能辨识出“猫”这个概念的视觉模式。这意味着能够轻松处理图像、声音等非结构化数据，这在符号主义 AI 看来是极其困难的任务。但是亚符号主义AI虽然能够辨别猫的概念，但基于大量数据的学习，这也意味着可能出现幻觉。

3、神经符号主义
	就是结合了前面两种范式优点的产物，既能像神经网络一样从数据中学习，也能像符号逻辑系统一样进行逻辑推理的混合。
	我们目前经常说的LLM，就是神经符号主义的极佳示例，内核是一个巨大的神经网络，使其具备学习能力，然后在它工作的时候会生产一系列结构化的中间步骤、计划或API调用，这些都是明确的、可操作的符号。
```
