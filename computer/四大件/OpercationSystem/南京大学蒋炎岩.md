# 一、OS历史



## 1. 计算机发展史

   

- **第一个阶段：电子管计算机 （1946 - 1958）**

  - ```
    第二次世界大战，英国为了计算炮弹轨道，需要大量的人工计算，为了替代人工计算机应运而生。
    最著名的电子管计算机就是ENIAC。它的诞生源于二战，是一个庞然大物，其拥有18000多个电子管，重量达30吨，占地1500平方英尺，运行耗电量150千瓦。
    真空电子管，体积大，容易损坏，还很耗电。
    现在我们使用的计算机中，已经看不到电子管的身影了
    ///////////////////////////////////////
    真空电子管：
    	实现逻辑门
    延时线：
    	用来存储数据。 其原理就是将数据转换成信号，ENIAC中是转换成电脉冲/声波，让其一直沿着一段有着固定传播速度和长度的介						质中无限循环转圈，通过一些控制器，在需要读取数据的时候，在信号到达指定位置将信号放大并转换成						  数据。
    ```

- **第二个阶段：晶体管计算机（1958 - 1964）**

  - ```
    1947年，贝尔实验室的三个科学家研制出一种点接触型的锗晶体管。他们日后也获得了诺贝尔奖。
    1957年，美国发明了完全使用晶体管的第二代计算机。
    晶体管比电子管功耗小、体积小、重量轻、工作电压低、工作可靠性好。用晶体管取代电子管，使计算机体积大为缩小，计算机的运算速度提高到每秒几十万次，比第一代电子管计算机提高了近百倍。相比电子管，晶体管拥有更小的体积，更低的能耗，更高的计算效率。
    ```

- **第三个阶段：集成电路计算机（1964 - 1971）**

  - ```
    德州仪器的工程师发明了集成电路（IC），集成电路（IC）顾名思义，就是把一定数量的常用电子元件，如电阻、电容、晶体管等，以及这些元件之间的连线，通过半导体工艺集成在一起的具有特定功能的电路。
    ```

- **第四个阶段：超大规模集成电路计算机（1971 - 至今）**

  - ```
    一个芯片集成了上百万的晶体管
    ```

    







## 2. OS发展史



- **1940s （手工操作时代）**

  - ```
    最早的电子计算机（如ENIAC、EDVAC）并不具备操作系统，程序直接通过打孔卡来输入程序。
    ```
  
- **1950s （批处理阶段）**

  - ```
    产生了集中管理计算机的需求，比如以前一个学校可能就一台计算机，很多学院很多人要用。
    批处理是指用户将一批作业提交给操作系统后就不再干预，由操作系统控制它们自动运行。
    通常是把一批作业以脱机方式输入到磁带上，并在系统中配上监督程序（Monitor），在它的控制下使这批作业能一个接一个地连续处理。
    【程序依然是一个接一个执行，不能做到多个程序并行】
    ```

- **1960s（执行系统）**

  - ```
    更大的内存，更快的处理器，更丰富的IO设备；完善的中断机制；虚拟内存的出现；
    基本上当今所有的程序，在这个时代也都出现了，或者说雏形已经出现了：第一个交互式图形界面、更多的高级语言与编辑器
    但是最核心的变化：允许程序并行，有了进程的概念，进程执行IO操作，允许将CPU让给别的进程
    				虚拟内存使得一个程序出BUG，不会影响其他程序，那个时代已经实现了内存空间地址的隔离
    ```

- **1970s**

  - ```
    CISC指令集；中断、IO、异常、MMU、网络；个人计算机的兴起；UNIX操作系统诞生
    这个时代的计算机与现在已经没有本质区别了
    ```
