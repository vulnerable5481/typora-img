## 1. DFS

- **递归序**

```3
什么是递归序？
比如一个树+代码          public void dfs(TreeeNode root){
							//1
     1						if(root==null)return;
  2    3					//1     这里可以做事
4  5 6   7                  //2
							dfs(root.left)
							//2    //这里可以做事
							//3
							dfs(root.right);
							//3	  // 这里可以做事
						}
递归序就是每次来到一个节点的时间顺序，在二叉树中每个节点都会来三次，具体在代码中来到的顺序看//1-3
这棵树的递归序就是： 1 2 4 4 4 2 5 5 5 1 3 6 6 6 3 7 7 7 3 1
递归序->衍生->> 前序后续中序遍历  第一次来到节点打印就是前序遍历
							  第二次来到节点打印就是中序遍历
							  第三次来到节点打印就是后序遍历
							  【一定要好好体会递归序，明白这个百分之九十的问题都可以解决了】
```

- **非递归版本DFS**

```
所有的递归都可以修改为非递归！递归本质就是系统帮你压栈入栈，手动实现栈也可以。
前序遍历：  一个栈就ok了
后序遍历：  两个栈就Ok了，无非就是前序遍历倒着来一遍
中序遍历：  一个栈即可，思想就是一直往左窜，左null才去看右
```

- **dfs解题思路**

```
从左右子树获取what?：
	1、要什么？就是我们究竟需要从左子树或右子树身上返回什么数据？比如返回左右子树最大深度？返回左右子树是不是搜索/平衡二叉树之类
	2、好好把握if判断，具体的操作是在递归序中三次时间的哪一次？判断好递归序，一切问题迎刃而解
	
标准解题思路：
	1、确定函数参数+返回值
	2、确定递归出口
	3、确定每一次递归都做了什么
	【其实前两步可以在写代码的时候再去构思，但是第三步事先必须想明白！也就是每一步递归该干什么？这一步有时候很困难很复杂
	 比如翻转二叉树：思路非常简单，每一步递归就是交换左右节点即可，最终整体就翻转了，想清楚每一步递归到底干啥！】
重要技巧：
	不要思考是那种遍历，只需要思考递归序即可->也就是第几次到达该节点需要采取行动，有的时候三种遍历都可以，有的时候只能用一种
	所以直接思考递归序更加直接了当！
```

## 2. BFS

```
public void bfs(TreeNode root){
	Queue<TreeNode> queue = new LinkedList<>();
	queue.offer(root);
	while(!queue.isEmpty()){
		int length = queue.size();
		for(int i=0;i<length;i++){
			TreeNode cur = queue.poll();
			// 处理
			if(cur.left != null){
				queue.offer(cur.left);
			}
			if(cur.right != null){
				queue.offer(cur.right);
			}
		}
	}
}
```

- **回溯中如何控制可选择集合**

  - 通过一个变量  **start**  来控制 筛选剩余集合

  - 合理控制start与i，可以决定是否从集合中的哪部分开始，比如是否允许重复元素的出现

    - 题目：集合1-9,求sum=7,每次只选3个数字 (**隐含条件：集合里面没有重复的元素**)
    
      - 不允许元素重复
    
        ```
        代码实现： 每次都让back(xx,i+1)，也就是遍历从当前元素下一个元素开始的集合不就实现了吗
        public void back(xx,int start){
        	xx
        	for(int i=start;i<=9;i++){
        		//
        		back(xx,i+1);
        		//
        	}
        }
        ```
    
      - 允许元素重复and顺序不同算同一个结果：223、115等都符合要求,232就不算
    
        ```
        代码实现： 每次都让back(xx,i)而不是i+1，也就是重新遍历包含当前元素之后的集合不就实现了吗
        public void back(xx,int start){
        	xx
        	for(int i=start;i<=9;i++){
        		//
        		back(xx,i);
        		//
        	}
        }
        ```
    
      - 允许元素重复且顺序无要求： 223、232、322都符合要求 
    
        ```
        代码实现：  每次都让i=0且back(xx,i)，也就是重新遍历集合不就实现了吗
        public void back(xx,int start){
        	xx
        	for(int i=0;i<=9;i++){ 
        		//
        		back(xx,i);
        		//
        	}
        }
        ```
