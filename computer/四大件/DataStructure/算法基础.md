## 1. DFS

- **递归序**

```3
什么是递归序？
比如一个树+代码          public void dfs(TreeeNode root){
							//1
     1						if(root==null)return;
  2    3					//1     这里可以做事
4  5 6   7                  //2
							dfs(root.left)
							//2    //这里可以做事
							//3
							dfs(root.right);
							//3	  // 这里可以做事
						}
递归序就是每次来到一个节点的时间顺序，在二叉树中每个节点都会来三次，具体在代码中来到的顺序看//1-3
这棵树的递归序就是： 1 2 4 4 4 2 5 5 5 1 3 6 6 6 3 7 7 7 3 1
递归序->衍生->> 前序后续中序遍历  第一次来到节点打印就是前序遍历
							  第二次来到节点打印就是中序遍历
							  第三次来到节点打印就是后序遍历
							  【一定要好好体会递归序，明白这个百分之九十的问题都可以解决了】
```

- **非递归版本DFS**

```
所有的递归都可以修改为非递归！递归本质就是系统帮你压栈入栈，手动实现栈也可以。
前序遍历：  一个栈就ok了
后序遍历：  两个栈就Ok了，无非就是前序遍历倒着来一遍
中序遍历：  一个栈即可，思想就是一直往左窜，左null才去看右
```

- **dfs解题思路**

```
从左右子树获取what?：
	1、要什么？就是我们究竟需要从左子树或右子树身上返回什么数据？比如返回左右子树最大深度？返回左右子树是不是搜索/平衡二叉树之类
	2、好好把握if判断，具体的操作是在递归序中三次时间的哪一次？判断好递归序，一切问题迎刃而解
	
标准解题思路：
	1、确定函数参数+返回值
	2、确定递归出口
	3、确定每一次递归都做了什么
	【其实前两步可以在写代码的时候再去构思，但是第三步事先必须想明白！也就是每一步递归该干什么？这一步有时候很困难很复杂
	 比如翻转二叉树：思路非常简单，每一步递归就是交换左右节点即可，最终整体就翻转了，想清楚每一步递归到底干啥！】
重要技巧：
	不要思考是那种遍历，只需要思考递归序即可->也就是第几次到达该节点需要采取行动，有的时候三种遍历都可以，有的时候只能用一种
	所以直接思考递归序更加直接了当！
```

## 2. BFS

```
public void bfs(TreeNode root){
	Queue<TreeNode> queue = new LinkedList<>();
	queue.offer(root);
	while(!queue.isEmpty()){
		int length = queue.size();
		for(int i=0;i<length;i++){
			TreeNode cur = queue.poll();
			// 处理
			if(cur.left != null){
				queue.offer(cur.left);
			}
			if(cur.right != null){
				queue.offer(cur.right);
			}
		}
	}
}
```

- **如何控制回溯序？**

  - 通过变量  **start**  来控制 筛选剩余集合，即控制回溯序

  - 合理控制start与i，可以决定是否从集合中的哪部分开始(即控制回溯序)，能够完成例如是否允许重复元素的出现等功能

    - 题目：集合1-9,求sum=7,每次只选3个数字 (**隐含条件：集合里面没有重复的元素**)
    
      - 不允许元素重复
    
        ```
        代码实现： 每次都让back(xx,i+1)，也就是遍历从当前元素下一个元素开始的集合不就实现了吗
        public void back(xx,int start){
        	xx
        	for(int i=start;i<=9;i++){
        		//
        		back(xx,i+1);
        		//
        	}
        }
        ```
    
      - 允许元素重复and顺序不同算同一个结果：223、115等都符合要求,232就不算
    
        ```
        代码实现： 每次都让back(xx,i)而不是i+1，也就是重新遍历包含当前元素之后的集合不就实现了吗
        public void back(xx,int start){
        	xx
        	for(int i=start;i<=9;i++){
        		//
        		back(xx,i);
        		//
        	}
        }
        ```
    
      - 允许元素重复且顺序无要求： 223、232、322都符合要求 
    
        ```
        代码实现：  每次都让i=0且back(xx,i)，也就是重新遍历集合不就实现了吗
        【此处的start实际上没有什么用了】
        public void back(xx,int start){
        	xx
        	for(int i=0;i<=9;i++){ 
        		//
        		back(xx,i);

        }

# 四、动态规划

## 1、基本介绍

```
使用场景：
	1、大问题的最优解可以由小问题的最优解组成，也就是可以通过解决很多重叠子问题，最终得到结果
	2、动态规划中的每一个局部状态都是通过上一个状态推导出来的，这一点就区分于贪心，贪心没有状态推导，直接从局部选取最优
贪心与DP：
	动态规划需要局部状态推导，每一个局部状态都是上一个状态推出来的；贪心没有局部推导，直接从局部选取最优即可
	比如，背包问题，用动态规划就是通过上一个物品推出下一个，贪心直接每次都拿最大/小的物品就好了，和上一个的状态没有关系。
回溯与DP：
	回溯就是穷举，DP则是子问题的最优解组成当前问题的最优解

解体步骤：
	1、确定dp数组以及下标的含义
    2、确定递推公式
    3、dp数组如何初始化
    4、确定遍历顺序
    5、举例推导dp数组
```

### ① 01背包

```
最标准最基础的01背包问题：
	有N件物品，和一个最大容量为W的背包，第i件物品的重量是weight[i]，得到的价值是value[i]。每个物品只能使用一次，求将哪些物品	  装进背包的价值最大？  
	解法思路：1、暴力解法：可以回溯穷举  2、动态规划
	
1、二维DP动态规划：
		   依然还是动态规划五部曲
		   ① dp[i][j]二维！i是第i个物品，j是当前背包的重量，dp[i][j]就是背包重量为j，可选择0-i物品的时候，最大价值是多少
		   ② 状态转移方程：IF j>weight[i] dp[i][j] = dp[i-1][j]
		   				else dp[i][j] = Math.max(dp[i-1][j],dp[i-1][j-weight[i]]+value[i]);
		   ③ 初始化： 就将dp[0][j]全部置0，将第一行能够放下物品0及其后面都初始化为物品0的价值
		   ④ 遍历：可以先按照物品遍历，也可以先按照容量遍历，个人习惯从容量开始遍历。
		   ⑤ 举例推导
		
        int[][] dp = new int[n][bigWeight+1];
        // 初始化DP
        for(int j=weight[0];j<=bigWeight;j++){
            dp[0][j] = value[0]; 
        }
        // 遍历DP
        for(int i=1;i<n;i++){
            for(int j=1;j<=bigWeight;j++){
         		// 如果当前容量装不下物品i，价值不变
                if(j-weight[i]<0){
                    dp[i][j] = dp[i-1][j];
                }else{
                // 装得下物品i，就先计算当前容量-物品i后的最大价值，再加上value[i]即可，很简单
                    int max = dp[i-1][j-weight[i]] + value[i];
                    dp[i][j] = Math.max(dp[i-1][j],max);
                }
            }
        }

2、一维DP
	一维的DP也可以解决背包问题
	仔细看之前的二维DP，其实可以发现当前这一行就是根据上一行加载的，我们自然可以正在一维数组上“滚动更新”
	【易错】主义千万不要正序遍历物品i,一定要倒序遍历，因为正序每次都依赖上一个(i-1)，但是上一个已经更新了，但是倒序的话，依赖的虽然也是i-1，但是倒序的上一个没有被更新，所以不会出现累加的情况，也就是一个物品出现多次。
	如果正序遍历：
        dp[1] = dp[1 - weight[0]] + value[0] = 15
        dp[2] = dp[2 - weight[0]] + value[0] = 30
	如果倒序遍历：
		dp[2] = dp[2 - weight[0]] + value[0] = 15 
		dp[1] = dp[1 - weight[0]] + value[0] = 15

	    int[] dp = new int[bigWeight+1];
        // 初始化数组
        for(int j=weight[0];j<=bigWeight;j++){
            dp[j] = value[0]; 
        }
        // 遍历数组
        for(int i=1;i<n;i++){
            for(int j=bigWeight;j>0;j--){
                if(j-weight[i]<0){
                    continue;
                }else{
                    int max = dp[j-weight[i]] + value[i];
                    dp[j] = Math.max(dp[j],max);
                }
            }
        }
