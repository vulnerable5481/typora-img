# 1、网络安全概述

```
1、信息安全目标包括五个方面：
	● 可用性
	● 完整性
	● 保密性
	● 不可抵赖性
	● 可控制性

2、TCSEC的安全等级：
	A     每一步都经过严密数学验证
	B3    安全管理员
	B2    安全结构化
	B1    强制访问控制;数据敏感程度，机密、绝密
	C2    日志系统，记录谁干了啥
	C1    用户、数据隔离开
	D     几乎没有安全措施

3、PPDR的四个标准：policy、protection、detection、response：策略、防护、检测、响应

4、MAC：强制访问控制：
	① 主体与客体，主体就是发起请求的，可以是程序、进程、用户；客体就是被访问的资源，比如打印机、数据库表、内存之类的
	② 最核心的特点：权限是系统管理员设置的，普通用户无法访问
	③ 标签：主体和客体会被打上标签，系统比较标签，判断主体是否有权限访问客体
	④ MAC与自主访问控制最大的区别就是，即使文件是我创建的，我也不能像自主访问控制一样随便设置给别人看/写，系统说了算

5、病毒、木马、蠕虫
	① 病毒：不能独立存在，必须寄生在可执行文件中；只有用户手动运行文件，病毒才会执行；运行后可以自我复制到其他程序中
	② 蠕虫：能够独立存在；会通过网络自我传播，自动从一台电脑蔓延到其他电脑，不需要用户点击；自我复制速度非常快
	③ 木马：不能独立存在；最大的特点就是伪装，会装成正常的软件、程序，被用户下载；主要是潜伏，窃取信息，不主动破坏
```

**TCSEC**（Trusted Computer System Evaluation Criteria），通俗被称为**“桔皮书”**（Orange Book），是由美国国防部于 1983 年发布的计算机安全评估标准。它是历史上第一个计算机安全评价准则，为后续的 CC 标准（ISO 15408）奠定了基础。

TCSEC 将计算机系统的安全等级从低到高分为 **D、C、B、A** 四个大类，共 7 个级别。

------

**TCSEC 安全等级划分表：**

| **级别**  | **名称**                                  | **核心特征**                                                 |
| --------- | ----------------------------------------- | ------------------------------------------------------------ |
| **D 级**  | **最小保护 (Minimal Protection)**         | **不安全。** 没有任何安全机制，典型的例子是早期的 MS-DOS 或 Windows 95。 |
| **C1 级** | **自主安全保护 (Discretionary Security)** | **入门级。**用户、数据分离开                                 |
| **C2 级** | **受控存取保护 (Controlled Access)**      | **商用标准。** 引入了**审计**（Logging）机制，记录谁在什么时候做了什么。 |
| **B1 级** | **标记安全保护 (Labeled Security)**       | **强制访问控制。** 系统对数据进行敏感度标记（如机密、绝密）。 |
| **B2 级** | **结构化保护 (Structured Protection)**    | **抗渗透能力。** 必须证明系统不存在隐蔽通道，安全功能被结构化划分。 |
| **B3 级** | **安全域保护 (Security Domains)**         | **高度安全。** 引入安全管理员角色，系统高度简化以便于进行安全审核。 |
| **A1 级** | **验证设计 (Verified Design)**            | **数学验证。** 系统设计的每个步骤都经过严密的数学证明，确保无懈可击。 |

**快速对比表**

| **特性**     | **病毒 (Virus)**     | **蠕虫 (Worm)**        | **木马 (Trojan)**      |
| ------------ | -------------------- | ---------------------- | ---------------------- |
| **独立运行** | 否（需宿主程序）     | **是**                 | 是                     |
| **自我复制** | 是                   | **是（极快）**         | 否                     |
| **传播媒介** | 文件传输、移动存储   | **网络漏洞、邮件**     | 伪装软件、社交工程     |
| **人为干预** | **需要**（点击运行） | 不需要（自动）         | **需要**（受骗安装）   |
| **主要危害** | 破坏文件、修改数据   | **消耗带宽、瘫痪网络** | **窃取信息、远程控制** |



# 2、网络攻击

```
1、主动攻击：
	① 篡改攻击
	② 欺骗攻击：
		● mac地址欺骗攻击：修改自己的MAC地址，伪装成目标的MAC地址，欺骗的是网卡
		● ARP欺骗攻击：   
		● 生成树欺骗攻击
		● DHCP欺骗攻击
	③ 拒绝服务攻击ddos：
		● smurf攻击：攻击者伪造IP地址给一个网络的广播地址发送ICMP Echo包，就是Ping包，网络内所有主机都会给受害者发送reply包
		● SYN泛洪攻击：利用TCP三次握手，给受害者发送大量SYN请求，服务器收到后发送SYN-ACK但是永远得不到响应，服务器不断发送并
					 将这个连接保存在半连接队列，资源就被耗尽了
	④ 重放攻击：截获信息之后过一段时间再发送给目标，或者不发送，或者反复发送
2、被动攻击：
	① 嗅探攻击：只是复制读取信息
		● MAC地址表溢出攻击：攻击者伪造大量MAC地址发送数据，使目标MAC地址表溢出，这样交换机此后收到的数据都会因为无法在MAC表找
						  到正确的地址，只能采取原始的广播方式，这样整个网络内都可以窃取到信息了，此时攻击者自然也能获取
	② 非法访问
```





# 3、加密算法

```
1、凯撒密码：A对应D
2、对称密钥、非对称密钥
3、对称密钥的加密算法：分组加密、流加密
4、攻击方式
	● 唯密文攻击：其实就是穷举
	● 选择密文攻击： 随意挑选一段密文或者伪造，骗对方解密，观察得到的明文，计算出正确的密钥K
	● 唯明文攻击： 不仅有密文还凑巧得到了对应的明文，推算出加密算法和密钥K
	● 选择明文攻击：  随意挑选一段明文或者伪造，可以得到密文，推算出密钥K
```

# 6、安全协议

```
1、 IPSec是网际层实现IP分组端到端安全传输的协议，其中又分为AH、ESP协议，两者都实现了IP分组源端鉴别+防重放攻击
	① AH协议（鉴别首部协议），只实现数据完整性检测
	② ESP协议(封装安全净荷协议)，实现数据完整性检测和数据加密

2、传输模式VS隧道模式
	● 传输模式：将AH和ESP插入到IP报头与传输层协议（TCP/UDP）之间
	● 隧道模式：将整个原始IP包都看做数据，在外面套上一层全新的IP报头，隐藏了真实IP地址

	传输模式是端到端
	隧道模式是网关到网关
	
两个办公室通过互联网连接，你想隐藏两个办公室内部电脑的真实 IP 地址，且必须保证数据内容不被窃听。你应该怎么选？
选择 A：AH + 传输模式
选择 B：ESP + 隧道模式

3、AH报文格式
	传输模式下： IP首部-AH-净荷
	隧道模式下： 新IP首部-AH-IP首部-净荷
	AH通过其格式中的序号进行防重放攻击的防御

4、ESP报文格式
	传输模式： IP首部-ESP首部-净荷-ESP尾部-ESP MAC
	隧道模式： 新IP首部-ESP首部-IP首部-净荷-ESP首部-ESP MAC

5、IKE
	是IPSec唯一的密钥管理协议

6、TLS在传输层。负责端口之间的端到端的安全传输
```
