# 一、罗马王政时期

（前753～前509年）

## 1、历史

```
  罗马共和国建立之前的几世纪内，为罗马王国，此时的罗马还是一个部落，尚未建立共和国。
  据罗马史，罗马王政时期最后一任国王卢修斯·塔克文·苏佩布的儿子强暴了一位贵族妇女卢克丽霞，并造成此妇女自杀，其亲戚布鲁图斯因此起兵推翻国王。前509年卢修斯兵败下野并被流放，罗马王政时代自此结束，罗马共和国正式成立。
```

## 2、政治

```
  罗马王国的政治制度就比较完整，统治阶层包括国王、元老院、人民大会。王不是世袭制，是由人民选举，但实际上由元老院控制。
```





# 二、罗马共和国

（前509～前27年）

## 1、历史

```
  罗马王政时期结束，罗马共和国正式成立。
  
  贵族时代：(公元前509年~前367年)
  		  ①护民官：王政时期结束，罗马共和国初期依然是贵族统治社会，在一次战争中平民士兵拒绝参战，迫使贵族允许平民选举一些新的官                   员维护平民的利益，平民将这些新官员称为护民官。
  		  ②十二铜表法
  		  
  权利纷争：(公元前367年~前287年)
  		  ①平民大会立法权增强
  		  ②《霍腾西阿法》：平民大会法律对全体公民有效
  		  
  对外扩张：(公元前287年~前133年)
  		  ①前264年-前146年罗马和迦太基之间为争夺地中海沿岸的霸权发生了三次战争，被称为“布匿战争”，最终罗马胜利。
  		  ②前214年至前148年，罗马发动过四次“马其顿战争”。最终击败马其顿王国，结束了希腊化时代。
  		  ③经过四次马其顿战争后，罗马征服了马其顿王国和整个希腊，又消灭了叙利亚的帝国，控制了西亚部分地区，成为了一个横跨亚欧非
  		  三洲，称霸地中海的大国，罗马共和国迎来了鼎盛时期。
  		  
  共和制衰落：(公元前133年~前49年)
  		  先前的时代能看到极大的战争上的胜利，以及极大的经济上的失败。
  		  走向衰落的主要原因：地中海帝国规模太大，而共和国制度只适用于一个城市国家：规模扩大 → 制度失效 → 内部矛盾爆炸。
  		  前82年苏拉率军占领罗马。次年，迫使公民大会选举他为终身独裁官，开创了罗马历史上军事独裁的先例。前60年，凯撒、克拉苏、庞           培秘密结盟，共同控制罗马政局，史称前三头同盟。前53年，克拉苏战死于安息。前48年，恺撒在内战中击败庞培，被宣布为终身独裁           官，集军政大权于一身。他厉行改革，但因独裁统治而招致政敌仇视，在前44年3月15日遭以布鲁图所领导的元老院成员刺杀。
  		  
  后凯撒时期：(公元前49年~前27年)
  		  凯撒死后，罗马内战又起。屋大维将两个政敌打败，于前27年元老院授与屋大维“奥古斯都”的尊号，建立元首制。屋大维大权在握成为           事实上的皇帝，罗马共和国结束了，古罗马进入了罗马帝国时代。
  		  
```

## 2、政治

```
  元老院：由曾经担任过高级官职的元老组成，不是直接的执法机关，但是权威很大，直接掌握国家大权，可以向执政官提出建议与指示，很大程度         上决定高级官员的人选。
  
  地方执政官：参议院为每一个共和国地方执政官分配了一个省，这是该职位任职者的权力范围，每一个执法官都拥有相当广泛的权力；帝王辖区的			  执法官由罗马执政官和巡抚担任。罗马共和国的执政官是最高级别的普通行政官，每人任期一年，实际上，他们将保留该职位的权力            （作为一个治安官），而不正式担任该职位。
  			在罗马城内，执政官是罗马政府的首脑。他们将主持元老院和议会的工作。在国外，每位执政官将指挥一支军队。 他在国外的权力             几乎是绝对的。执政官管理民法，指挥各省军队。
  			特殊情况下，比如突发战争等，在元老院的建议下，会选举一个执政官来解决危机，任期最长为6个月，任期内独揽大权。

  公民大会：主要是由百人大会(可以选举执政官，裁判长)、市选区大会(按地区划分可以选举部分官员)、平民大会组成(选举保民官)；
           罗马的公民身份不是可以轻易取得的，也是众多重要法律权利的前提。最初公民与平民有很大区别：公民是法律身份，平民是阶层，
           平民通过十二铜表法、平民议事会、保民官等为自己争取更多的权益。

  法律的演变发展：
  	   1、习惯法：共和国早期通过祖先传统、经验等对案件进行审判，实际上完全由贵族掌控
  	   2、十二铜表法：公元前450年，这是罗马法律史的一次重大变革，是罗马史上第一部成文法，尽管内容仍偏向贵族，但法律公开化是革命                     性的。
       3、市民法与万民法：市民法是针对罗马公民的法律，万民法是随着罗马不断征服外邦，为处理外邦人产生的法律。
	   4、自然法：帝国时期，受希腊哲学影响，哲学家和法学家们提出理性、公平的自然法则，如人人平等，成为法律的最高准则。
	   5、《查士丁尼法典》，六世纪：东罗马皇帝查士丁尼组织编纂的《民法大全》，汇集了前代法律，包括《法典》、《法学阶梯》、《学说           汇纂》和《新律》，将罗马法体系化、集大成。 
```

## 3、个人感悟

```
  罗马共和国时期，平民为自己赢得了很多权利，比如保民官、十二铜表法、平民大会的立法权，但这些政治/制度的获得并不等于社会经济和政治地位的根本变革，实际上他们仍然是遭受压迫的阶层，平民的生活条件没有得到改善，由于战争原因还遭受损害，保民官等职务甚至形成了新贵族。   碍于时代的局限性，导致压迫持续存在，但民主与人人平等的精神终将实现。
  ① 法律制度的进步：习惯法->十二铜表法
  ② 立法权：平民大会通过的法案对罗马共和国全体公民生效
  ③ 保民官：平民阶层拥有成为官员的机会，保民官等设立之初的意义便是为平民谋取权利
  ④ 专权的部分制衡：如同一地区执政官需要同时有两个人；元老院、公民大会、执政官互相制衡等
```





# 三、罗马帝国

（分裂前：前27年~公元395年，西罗马：公元395年~公元496年，东罗马：公元395年~公元1453年）

## 1、历史

```
  罗马共和国的末期，凯撒被元老院封为终身独裁官不久便遇刺身亡，频繁的内乱搅得政局晃荡不安，直到屋大维击败政敌，元老院放弃共和制，赐君权及奥古斯都头衔于屋大维(奥古斯都，罗马帝国皇帝的头衔)，这象征着罗马共和国的终结。
  罗马帝国建立后，这时元老院仍然存在，但大权已掌握在屋大维手中。屋大维征战胜利，扩大了帝国疆域，此后两个世纪帝国政局迎来了稳定，被成为“罗马盛世/罗马治世”。元老院后来封涅尔瓦为皇帝，这亦是罗马五贤帝之首，开辟一段长达八十多年的政局稳定时期。罗马第13位皇帝图拉真是罗马五贤帝之中的第二位，他在位时见证帝国的最大版图。康茂德在位时，帝国开始出现衰退之兆。公元192年康茂德被刺杀身亡，触发五帝之年，有五人同时称帝，乱象最后由塞普蒂米乌斯·塞维鲁取得胜利而告终。后来的戴克里先为了稳定罗马帝国的版图而将帝国分为东西两部分，立马克西米安为第一任西罗马皇帝，作为副帝，授予“奥古斯都”头衔，同时也是罗马帝国第一次分裂。不久后便推行四帝共治制，但在戴克里先退位后制度大崩解，一度出现六个政权同时存在的画面，最后由西部皇帝君士坦丁大帝打败东部皇帝李锡尼，帝国再度统一。君士坦丁大帝在位期间不仅对外征服失去多年的达契亚，同时也对基督教实施宽容制度，他建立了许多教堂，帝国才全面恢复稳定。后来君士坦丁一世迁都至拜占庭，并命名为新罗马，但我们更喜欢称之为“君士坦丁堡”。君士坦丁堡自此之后一直是帝国的首都，一直到其终结。这时的罗马帝国仍然是世界上的强权，并与其东面安息帝国的继承者波斯第二帝国互相抗衡，持续着一个世纪的纷争。
  君士坦丁死后帝国陷入了两次分裂，分别由君士坦提乌斯二世和狄奥多西一世统一，狄奥多西一世是最后一位统治过完整罗国帝国的皇帝，其在位时发布了萨洛尼卡敕令，宣布基督教为国教，但狄奥多西一世死后分别立自己的儿子霍诺留和阿卡狄奥斯为西罗马帝国和东罗马帝国皇帝，之后罗马帝国从此再未统一。
```

## 2、政治

```
  【罗马皇帝】：与古代东方君主制国家相比，罗马帝国没有固定的皇位继承制度，在元首制下，皇帝拥有最高统治权，大多数皇帝都希望讲皇位世袭，但由于共和传统的影响，元首的产生应由元老院来选举产生，皇位的世袭缺乏一个理论基础，在罗马，元首是一个官员，担任元首是一种义务而不是一种权利。而选举的理论却在集权下显得非常脆弱。罗马帝国皇位继承的正统原则是选举原则。选举原则是共和时期的选官原则，帝国时期成为元首产生的重要理论依据。罗马帝国是建立在五百年共和历史的基础上，因此制度的建设必然会受到共和传统的影响。奥古斯都创立的元首制虽然本质上 是君主专制，但表面上遵循了共和旧制。在元首的产生上，选举原则以及元首本身内在含义限制了元首世袭理论的建立。
  罗马的元首不同于东方的君主，在东方是君权神授，君王的权力被认为是上天赐给的，是与生俱来的。这种权力是私有化的权力，是属于某个热的权力，所以在皇位传承中就可以将这种权力顺理成章地转移给继承人。而在罗马，皇帝的权力是受委托的权力，是授权给一个理论上由罗马公民选举或认可的个人使命。权力是授予某个特定的个人的，随着个人生命的终结，他所拥有的权力也就终止了。即帝国的最高大权不是由个人转交给另一个个人，而必须以国家为中介。因此，罗马皇帝就是一个国家代表接着另一个国家代表。从这方面说，罗马皇帝之间就不存在继承问题。他们的权力是从国家——元老院和人们手中接掌的，就像执政官在同一个职位上彼此替换。这样，在理论上不存在皇权一脉相承。尽管王朝的更迭已成惯例，一个罗马皇帝并非自动通过世袭权利来接替他的父亲，只有在得到明确授权的条件下，他才能继承父业登上皇位。
```





# 四、西罗马帝国

## 1、历史

```
  西罗马帝国是罗马帝国自286年被戴克里分为东西两部分，把政权分为四帝共治，自此东西罗马帝国的区域分裂概念诞生。此后，罗马帝国常出现多个政权，但名义上依然是一个整体，皇帝们都被授予“奥古斯都”，但有主副之分。后来西罗马帝国的君士坦丁大帝不满足分裂现状，击败了东罗马皇帝李锡尼，赢得内战重新统一罗马，成为全罗马帝国的皇帝，之后迁都拜占庭，改名为“君士坦丁堡”。位于西部的部分是在395年，君士坦丁大帝将东西罗马分别授予两个儿子，自此罗马帝国彻底分裂成东西罗马帝国。不过当时的人们不认为罗马帝国分裂了，而是视为两个朝廷管理的单一政体，后来西罗马帝国不断衰落，最终476年被日耳曼吞并。
  480年以后，东罗马帝国的芝诺皇帝也不再拥立新的西部皇帝，而是先后册封入主西罗马旧地的日耳曼裔统治者奥多亚塞及狄奥多里克为意大利国王。普遍认为476年，西罗马帝国的灭亡标记着古代欧洲的结束，中世纪的到来。
```
