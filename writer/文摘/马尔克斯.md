





# 《一桩事先张扬的凶杀案》





- 当我重返这个被遗忘的小镇，想将散落的残片重新拼成记忆之镜时，我看见她卧在吊床上，苦熬暮年最后的光阴，她曾经就在这同一张吊床上用同样的姿势端详着自己的儿子。即使在白天，她也辨别不出旁人的轮廓。**她的太阳穴上贴着几片草药叶子，用来缓解儿子最后一次走过卧室时给她留下的永难治愈的头痛。**她侧着身子，抓住吊床一头的绳结想做起来。**房间昏暗处弥漫着**那个罪恶的清晨曾令我惊悸的洗礼池的气味。

- ```
  1.儿子逝去的早晨，母亲曾见过儿子去浴室拿药经过卧室的景象，那是母亲最后一次见到儿子，而这一场景留给目前永难治愈的头痛。
    相当精彩的魔幻现实
  2.房间昏暗处弥漫着XX气味，气味弥漫在昏暗处，有点意思。
  ```

  



- 我在她的回忆里看见了圣地亚哥·纳萨尔。
