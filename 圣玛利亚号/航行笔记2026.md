## 《如何判断读一本书有所收获》

```
  一本书读完了，常会想到一个问题，读完书后我有收获吗？我从书中到底得到了什么？这个问题是很严厉的，一但回答不满意，自己读的那些书籍就失去了意义，到头来都是一场空，自己有义务也必须正面回答这个问题。
  我将从三个方向来进行答复：感受、内化程度、输出、
  从书的类型来回答，我们可以将书的类型简化为故事书和知识书两种，当然细分下来，类型肯定不止如此，但大体都在这两种范围内。首先是故事书，以我个人为例，像是推理、科幻、经典文学作品都算是故事书，一些内含丰富知识但故事写得好的书我也可能会归为故事书。对于故事书，读者的核心诉求是倾向人文，倾向感性的，所以刚刚读完一本故事书，你此刻内心的感受就是最大的收获。当我第一次读完《百年孤独》，那时我还在高中，恰逢考试失利和内心迷茫，那一刻我真的看到了店外，马孔多的雨淅淅沥沥，空气中混杂着雨林的气息。也许我现在已记不清书中人物的名字，核心剧情我可能都说不上来，但是那种感觉一直都刻在记忆的某处，时常浮出来，当你不经意间发现它的时候就会明白这本书已经深深印在了你的魂中。所以我认为故事书对内心世界的冲击，那种无法言说的感受----遗憾、迷茫、空虚等等就是最珍贵的收获。当然不只是感受，带着不同的视觉去阅读，比如我本人是以作家为目标的，阅读中自然会留意文字、故事架构、写作技巧，同样的也能通过故事书跨越时空间去体验现实中难以触及的生活等等这都是收获，但渗透我们一生的那种感觉永远是最大的收获。
  知识书，像是计算机相关的专业技术书、思想启蒙类的哲学书、金融理财类的书这都是知识书，对于知识书，读者的核心诉求是倾向知识、倾向理性的，所以读完一本知识书最大的收获就是你从中学到了自己需要的知识。当我第一次读完《汇编原理》这本书，我真的在脑海中搭建出了计算机底层的一些形象，过去我对汇编可能仅仅停留在它是一门机器语言，专门给机器使用的底层语言，但是汇编及其作用我是看不见的，在我已有知识体系中，它是不可见摸不着的，这种模棱两可停留在印象的知识不属于你，所以我当时读这本书就是为了将其纳入我的知识体系中，借助汇编来尝试窥探一下计算机底层的一些秘密，实际上这本哲学家学的计算机作品确实做到了。当然计算机是我的专业，对于这些书籍我会抱着严谨认真的态度阅读，但是也有很多轻松阅读的知识书，阅读前我会带着问题，不一定非要吸收整本书所有的知识，我更多的是为解决问题，如果中途能有别的收获那也是好事。所以将知识纳入自己的体系中，使其是看得见摸得着的知识，这就是收获。
  最后是输出，你读完一本书能否将一些感受与知识输出也是评判有所收获的关键，当你阅读完一本故事书可以尝试总结故事梗概、模仿写作技巧、通过撰写书籍专栏、向他人推荐等形式输出，知识书就更简单了，记录笔记、整理技术博客文档、自我讲课等方式，但一定要有输出的过程。输出是检验知识的唯一标准，如果你做不到输出那必然有错误需要修正。   
  																							    4.x
```

## 《阅读史--纸质书》

```
  有人问我阅读是什么，我会说：阅读首先是一门爱好，其次是获取知识的途径。
  小学：二年级我看了一本查理九世----冒险系列读物，这套书算是我阅读的启蒙，第一部《黑北街的亡灵》也是记忆中读的第一本书，此后便一发不可收拾。当时班里有个女生读完一本查理九世，便会二手卖给我，原价七块钱一本，我买只用五毛钱，真是个善良的人；跳蚤市场，一次校园跳蚤市场，大家会提前把要卖的物品上报给班长，然后组织班里几个人到操场过道讨卖，那场景好不热闹，印象中自己忍痛卖了两本查理九世，又买了两本查理，最后还是亏了几块钱，不过新买的旧书到手也就满足了；我自己也会买书，不过大多都是买同学可剩下的旧书，偶尔赶会的时候也会哭闹着让妈妈买几本书，一本是查理九世全集，可惜那本查理九世全集是盗版，二十元一本，超过一半的篇章全都没有结尾，到中间就断了，另一本是西游记，一次午后随手放在了楼梯上，碰巧下雨，也就真如经书一样被水泡湿了，后面学着唐僧师徒晒干却也无心再读；共享书屋，四、五年级的小学语文老师办置了一个玻璃书柜，老师让大家把自己的书放到共享书柜，方便互相借阅，只记得读了《撒哈拉沙漠》、《草房子》、查理九世盗版第二部、部分查理九世第一部、《怪物大师》、杨红樱的《笑猫日记》、沈石溪的动物系列等等，还有一本抗日题材的书，依稀只记得一个汉奸似的人物，他的脸是用屁股上的一块肉补上去的，这段描写记忆犹新。当时我还把自己当时最珍贵的《青铜葵花》放进去了。我的阅读习惯就是这位语文老师通过共享书屋培养的，她是我遇到的最好的老师。追忆至此，突然感叹自己小学时光多么美好啊。
  初中：这段时期自己看书真不多，印象深刻的就四本，第一本是刚来城里去书馆买的最后一本查理九世----《香巴拉，世界的尽头》，后面就被官方下架，而且自己也不再满足看儿童读物；第二本是向同学借的《解忧杂货店》；第三四本是《骆驼祥子》与《红与黑》，直到现在我也总认为这两本书很相似，甚至说是一本书。
  高中：自己真正开始大量阅读是在高二，那时候真心讨厌上课与考试，宁愿多看一本书；这个时期自己开始大量阅读推理、科幻小说还有余华的作品,买了很多书，尽管没有书架但我可以放到衣柜里面，直到今天，我新购置的书还是会放到衣柜里；
  大学：如果是高中时期自己是按照兴趣大量阅读某几类书籍，那么大学期间自己开始广撒网，会去阅读互联网技术书籍、哲学、心理、历史、财经等领域，用来拓展视野与丰富技术能力。
  工作后：我承认自己工作后相当一段时间都无法拥抱纸质书，自己开始用电子书缓解工作后遗症，打破对电子书的固有偏见，这才又重新读起书了；最近自己打算拾起纸质书，有些书还得慢慢翻页，细心品读。
```

## 《实现资产流的十个'动机'》

```
  1、自由：我向来自诩自由的人，但我并不自由，还总是装出一副自由的样子，到头来我才是被世俗束缚最深的那一个，但即便如此我还是发自内心的渴望自由。尽管实现资产流不一定就等同于得到自由，但被财务问题所困就一定会失去自由。
  2、书籍：一间只属于我的图书馆，无需多言。
  3、伙伴：我曾经有很多朋友，他们被生活煎熟，反倒我和他们不熟了，我很希望能够拯救被生活破坏的友谊，梦里多次想到自己有了足够的资产后，带着朋友去航海探险，一起游山玩水，或者和朋友一起创业，做些年轻人该去拼搏的事情，这样的想法有很多，但是没有资产，自己有什么本事敢去拯救别人？
  4、亲人：对于很多人来说，包括曾经的我，没有太多资产也不算很糟糕的事，只要有份稳定的工作，每个月开销也不算大，爱好也就阅读和动漫电影啥的，大头也就是买些游戏设备，即使工资不多我也能活得很开心。但一想到身边的亲人要是遭遇意外急需一笔钱的时候，我能做什么呢，如果担负责任平淡的生活就会破灭，不担负责任自己又与禽兽二异？
  5、灵感：我最贴近现实的一个梦想就是当一位作家，而作家最需要的就是灵感，交换世界，是我的一个人生计划，其作用就是让我体验到不同的人生，，以此拓展视野。很明显这个计划的上下限落差是很大的，没有足够的资产我连游山玩水的机会都少得可怜，世面都见不得，还交换啥啊，还去哪找灵感呢？
  6、航海：你知道的，其实我一直都有一个航海梦，能够独自驾驶一艘小船在海上漫游，不经意间邂逅了一座生长着椰子树、围着白沙滩的无人小岛，白天上岸搭一个树屋，下水捉龙虾，晚上躺在小屋里看着星空入睡；也会在暴风雨夜航行在海中，下面是海，天上也是海，稍有松懈就可能天翻地转，一命呜呼，整夜都要专注控制船的航向与稳定。
  7、旅游：这是获得灵感的核心方式之一。
  8、精装：希望能拥有最好的设备用来玩游戏，追番看剧，提高生活质量。
  9、选择障碍：我有选择障碍，吃饭与购物的时候经常会遇到选择障碍，如果有足够的资产，我想会立马治愈这一心理疾病。
 10、放逐宇宙：我希望自己在生命的最后（非自然死亡）可以来一场宇宙漫游，我要把自己亲手放逐宇宙，这也算是一种自杀吧。我乘坐着一艘宇宙飞船（有去无回的也可以，比如未来有一次性火箭，勉强能载普通人）一直向着一个方向前进，这注定是没有归途的旅行，更糟糕的是可能我还没离开大气层就已经say goodbye了，所以为了能尽量活着抵达宇宙，没有一定的资产是万万不行的。
```

## 《写作基调·1》

```
  1、推理症候群，从高中开始自己阅读的书籍中一半都是推理书，深受社会派、变革派、设定系等不同派别影响，尤其是麻神和白井的毒害，我以后写的书也会是疯疯癫癫的，不走寻常路！尽管我没有本格推理作家那样的严谨思维，但是我确信自己能写出变格风的故事，如果要定义一个派别，我是社会变格杂糅设定派。自己并不打算写推理小说，而是要把推理小说中的各种元素化为写作风格：叙述性诡计(叙诡)、新本格天马行空的想象(完全不讲逻辑呢)、本格推理的逻辑嵌套、变格的魔鬼呢喃、设定系的架空世界、麻神的反套路、白井的新生代集成等等，我要把推理小说中的各种元素广泛地应用到写作中，其实有点类似东野圭吾了，东野的写作风就是广泛使用推理元素的典范，值得学习。
  2、一种偏见：只有悲剧才是好作品。遗憾与悲剧，最容易勾起人的情绪，回味无穷。
  3、漫画与悲剧：平常的悲剧是费尽心思塑造的角色在中后期死去（有时候活着比死亡还令人难受）或者相恋的人无法走在一起；我理解的悲剧还包括在角色塑造结束前就突然死亡，要起到一种戛然而止的效果（详见藤本树）；让悲剧融入日常（详见藤本树）；
  4、怪诞现实主义：疯癫主角与克苏鲁细节，主角要能与死物对话、梦、平淡剧情中的克苏鲁细节,这听起来像是魔幻现实主义，那是必然的，高中读了余华、莫言当然还有马尔克斯的书，人自然会迷上充满魔幻色彩的现实小说；但我会在魔幻的基调上加些佐料，怪诞现实主义！
```

```
									    淀粉肠谋杀案
  A同学死了，死在一个没有淀粉肠的夜晚。
  无聊的又一天，一事无成，活在就业焦虑中，一如既往的废物，窝囊废啊，你到底能做出什么有趣的事情呢？抱着这样的心情，A同学缓缓打开了色情网站，屏幕上裸露的女人那夸张的表情令他心生厌恶，裤子里的手像蛆一样蠕动，不一会又像虫子那样爆裂开，白色的浊肉混着女人的叫声，潮湿而粘腻，令人闻之极其不快。直到息屏，看见屏幕上干裂微张的嘴唇，嘴角旁歪着一颗瘤子，油塌塌的鼻子上面挂着像被人用生殖器怼着凹陷进入的眼球，真是丑态毕露啊。拖着这样松垮的身体走向浴室，手依然深陷内裤内，仿佛石中剑！就像大脑事先输入过指令一样，每天都是如此，洗完澡后就是躺在床上看小说，浑浊且敷衍地过完下午。洗完澡身体倒是清爽多了，但心里始终被恶意包裹，起初恶意只是侵占了A同学的大脑，后来顺着他的目光滑向了天空，转瞬间染黑了大片云，不多时，整个天空都暗了下来-----浸透着恶意的夜晚终于降临。
  坠落前的三分钟，将死未死的A同学决定去校门口买一根淀粉肠，但当他发现此时连淀粉肠都抛弃了他----十二点校门已锁，他再也没有顾虑了，去他妈的社会，去他妈的淀粉肠，A同学怪叫着冲出宿舍，一跃而下。经常跳楼的人都知道坠落的过程是漫长且无趣的，A同学此时脑海里又闪过什么走马灯呢，我不知道，兴许是挂满皱纹的父母，是夜光下温柔的倩影，或是年轻充满期待的自己。事实上，直到死亡降临的最后一秒，A同学的脑海里都飘满了淀粉肠的香味？？香味？？A同学挣扎着让自己的头抬起来，顺着香味，他竟闻到对面一间宿舍内竟有五根淀粉肠！那是孜然的香味、黑椒的浓郁、蒜香的微醺，还有狗屎一样的番茄(最难吃),他仿佛看见五根淀粉肠整齐地摆在桌上，油亮的表皮泛着微黄的光，口水从A同学的嘴中流出，突然那油光下，有什么东西在蠕动，他想要揉一揉眼睛可是做不到，因为那蠕动的淀粉肠正是自己的手和脚，A同学忽然意识到刚刚的口水是自己的血液，香味也不是从宿舍对面飘来，而是.......从他自己身上。
  A同学死了，死因是后脑勺着地。“刚查过监控，坠落时这孩子头突地一抬，身体发生侧翻，后脑勺着地，太倒霉了，假如不是那一抬兴许还有一条命在，也就比我小几岁。”旁边负责记录的年轻警察可惜地说到，年轻警察望着A同学冷冰冰的身体，唯有头颅中两颗空洞死死盯着对面的一间宿舍，警察顺着目光看去，只看到一间门匾上写着3B214的宿舍，还有垃圾桶上几根吃剩的淀粉肠的竹签，以及一只苍蝇。
```
