# 2、能力培养

## 2.1、局部白描

首先你要具备基础的描述能力，能够随手描写一朵花，一个人。

## 2.2、动态白描

你要能够描述一个动态的过程，比如一件完整、连贯的过程。

## 2.3、全局白描

你要能够描述一件完整的事情，有开头、起伏与结尾。

## 2.4、专项训练

当实现了前三点，你就具备就最基础的表述能力，这时候需要持续对不同场景进行专项训练。

【这是一个长期的过程，或者说是对前三点的巩固与训练】

## 2.5、故事设计

现在你具备了描述的能力，但还需要设计出新颖的故事情节。

```
1、故事的开头
2、故事的发展
3、故事的结尾
```

## 2.6、主旨

现在你能讲好一个故事，但好故事总得有核心主旨，能够让人无法忘怀。

## 2.7、个人特色

你现在可以讲好一个好故事了，但是这也不是什么难事，最难的是有个人特色，我反而认为26和2.7是前期的我最不匮乏的，我有太多灵感与想法了，也许后期我才会遇到这种问题。
