# 作家

```
现在开始

1. 描绘自己身边的一些人，一些事，描述自己的心理状态。

2.坚持每天早上写作。坚持造成一起来就写作，不要干任何事，而是写作。坚持第二天再来，并且不能阅读之前写的内容。（把铅笔和纸放在床头，每天早上一起来就写）。

3.选定一个时间，每天坚持写十五分钟。之后，尝试换一个不同的时间段，再进行写作。

4.回顾自己之前的作品，发现自己的风格与写作兴趣与主题。

5.两个自我的对话，批评自己的作品并修改。

6.总结产生优秀作品的条件，并坚持规律的生活。

7.剖析自己喜欢的书。提出问题，带着批判的眼光再读第二遍。

8.挑选自己喜欢的作品，进行模仿。

9.学会重新看世界。

10.保持原创性。

11.不要沉迷阅读，珍惜休闲的时间进行创作。

12.发现自己的风格。选择主题，构想故事，填充素材，然后开始创作。然后隔一段时间，客观地评价她。

13.无意识、孤独。

14.保持平静，让思维流动，故事自然成形。

注意：在写一部作品时，不要阅读和自己作品主题相似的书。
```

```
										秘密王国
    我曾经有很多超前的想法，假如我能够将它们实现，我现在会是一个内心强大、充满自信、能力出色、温柔善良的人。但在过去，我总是眼睁睁地看着自己的想法被周围的人实现，他们不断变得优秀，我却与之前没有明显变化。嫉妒、憎恨，这些恶意涌现在我的内心。我恨他们！那明明是我的想法！本应该由我实现才对！但终归是我个人的懦弱与懒惰造成的，也只好把这恶意深深刻在心里，讲真的，我不想承认自己厌恶他们，因为他们很多人都是我的朋友，甚至是挚友与发小。我要把这些恶意当做动力，这才是挽回的举措。
    直到今天为止，我终于开始对自我的彻底改造，我要杀死过去的自己，其中包括我对他人的憎恨与恶意-----那曾是我生命的一部分。我要通过建立一座属于自己的“秘密王国”，通过文字与笔记的形式一步步搭建它。目前它还不成熟，但我已经处在高效施工的状态，我想自己终有一天可以完成。
    秘密王国。其实就是我在github等代码平台的一个项目，里面由各种笔记构成。我希望将自己掌握的知识、总结的经验、未来的规划以及我自己的人生都写进去，也许未来会有人看到，真心希望其中的内容对他有帮助。我目前正在将自己掌握的知识以笔记的形式记录其中，将阅读的书籍、动漫、电影等心得体会都记录其中，也会将自己的人生规划记录其中，我将终其一生创作我的“秘密王国”。
```
