# 一、AT&T





## 1.生命周期

- **诞生**

  - ```
    1877年，电话之父亚历山大·贝尔创建了贝尔电话公司
    1885年，因为长途电话业务，又开设了AT&T子公司
    1984年，贝尔电话公司经过反垄断拆分之后，公司的主体采用了AT&T的名称
    ```

- **发展**

  - ```
    这里基本就是将生意从纽约地区扩展到美国的其他地区，1927年，长途电话业务又拓展到了欧洲。
    ```

- **分裂**

  - ```
    1984年，贝尔电话公司触犯反垄断法，根据地区拆分成8个小贝儿公司从事市话业务，而母公司即AT&T公司从事长途电话业务和通信设备的制造
    ```

- **巅峰**

  - ```
    AT&T公司并没有因为拆分而走向衰落，反而因为反垄断法的修枝裁叶，让其业务更加集中，使其在通信和半导体技术领先全球，到1994年，营业额已经超过700亿。同年，贝尔实验室的总裁John Mayo博士率访问团访华，中国国家主席江泽民亲自接见！
    ```

- **灭亡**

  - ```
    1995年，AT&T公司发展到了顶峰，但任何事物的发展总是由顶点开始跌落，AT&T公司也不例外。
    接下来几年，AT&T公司在内部错误的决策和外来冲击下，迅速跌落谷底，最终由曾经的8个小贝儿公司中的SBC吞并。
    如今的AT&T公司早已经不是曾经的AT&T公司，只是名称沿用。
    ```

    

## 2.衰落原因



```
AT&T公司从十九世纪七八十年代开始，历经百年的洗礼，稳扎于通信行业，凭借着全球领先的通信、半导体技术和精明的商业策略成功建立起辉煌的商业帝国。
很多人遗憾，在人类信息技术高速发展的黄金世纪初，AT&T公司本应乘风而起，成为商业界的罗马帝国。何况AT&T公司有着百年历史底蕴，经历过多次经济危机，一战、二战等重大历史事件的冲击，依然稳扎于通信行业，不断发展扩大，却又偏偏倒在21世纪（2000-2010）-----美国经济发展最快，全球信息大爆炸的时代？
我认为主要由两个原因造成：内部错误的决策 和 外部冲击
```



- **内部错误的决策**

  - ```
    在2000年前后，短线投资者发现最快的挣钱方法不是把一家企业搞好，而是炒作和包装上市。将公司的一部分拆了卖无疑挣钱最快。
    AT&T公司的董事和执行官就执着于拆分公司的业务，在全球从传统电话到移动电话转型的关键时期，拥有丰富经验和领先技术的AT&T公司本应该走在时代最前沿，与当今的通信业竞争对手一决高下，但内部核心管理人员却忙着搞拆分，白白错失良机。分家之后，公司已经没有足够的资金和完整的技术链去与对手竞争，最终只剩下一个不断下滑的老旧业务
    ```

- **外部冲击**

  - ```
    新兴公司的迅速崛起，把握住了移动电话转型的良机，固定电话不再是人类唯一的交互通信手段。因此只要是站在时代的风口浪尖上，哪怕不做任何事，也可以被它的波浪推着前进，AT&T公司过去百年就是这样发展过来的，它不紧不慢地发展着，即使中间有很多失败的投资，但都没有丝毫地伤害它，也不能阻止它一次又一次形成垄断。
    ```

# 九、雅虎





## 1.生命周期





- **诞生**

  - ```
    上世纪九十年代斯坦福大学，杨致远、费曼和另外第三个同学趁教授外出学术度假一年的时间，放下手中的研究，转而开发一款为互联网做分类整理和查询网站的软件---最初的雅虎，这个工具被放在斯坦福大学校园网上免费使用，互联网用户发现可以通过访问雅虎，再从雅虎访问其他网站，减少了支付费用。门户网站的概念也就此形成了。后来雅虎的访问量不断上升，斯坦福大学的服务器无法支撑，网景公司赞助给雅虎一台服务器，杨致远和费曼从此脱离校园，开始创建雅虎公司。
    题外话：最开始的第三个同学因为考虑到学业等问题，与时代浪潮失之交臂。
    【时代背景：当时互联网并不是免费的，用户和客户是同一个人，每一次查询都需要缴费】
    ```

- **发展与巅峰**

  - ```
    1996年雅虎公司正式创立，直到2002年之前，雅虎创造了互联网奇迹，在搜索引擎和传统品牌广告领域长期压制微软，成为世界上最大的互联网公司
    ```

- **衰落**

  - ```
    在2003年之后，雅虎公司与google分道扬镳，并且在与其竞争搜索引擎市场中大败，后又经历了五年七换CEO等起伏，最终一蹶不振，迅速走向衰落。
    ```

  

## 2.衰落原因



- **公司定位混乱**

  - ```
    雅虎并非像google、微软那些互联网顶头一样拥有绝对的技术领先，实际上雅虎大部分时间都是作为一家媒体公司，而非技术公司。
    在网络泡沫破灭后，互联网公司本就已经遭到致命打击，雅虎还雪上加霜，把自己搞得四不像，技术上本就没有任何领先，假如选择与谷歌合作，使用谷歌的搜索引擎，凭借着原有的老牌广告产业，稳步发展，另寻良机，也不至于落得如此下场。
    ```

    





## 3. 收获与反思



- ```
  通过雅虎公司的发展历程，结合中国的实际情境，我想如果我要是去做产品，也要遵循免费开放的原则，就像雅虎公司一样选择将互联网免费开放，以此吸引大量traffic，通过品牌广告产业来获取利益。
  其实这个道理并不陌生，你去开发一个产品，比如开发了一个某功能的软件，刚开始肯定要便宜甚至免费，吸引traffic，等用户多了在割韭菜，这个老生常谈，但是最大的收获开始不要被traffic蒙住双眼，不要本末倒置，为了追求traffic而无效投资。
  ```

# 十二、风险投资

## 1.风投起源

- **传统创业资金来源**
  - 任何一家公司的创办都离不开资金。传统的创业资金的合法来源只有两种渠道，一是靠积累（个人的积蓄或继承遗产），
    二是靠借贷（向家人、朋友借钱或者从银行抵押贷款）	

- **风险投资**
  - 假如你已经有了一笔不菲的积蓄，你应该如何打理？购买稳定的黄金or国债，还是将资金投入股市？但这些方法的回报率往往
    只有不到10%，而且回报周期长。
    那如何做到短时间将积蓄翻上一番？有两种方式，一种是收购长期盈利但暂时遇到困难的企业，比如投资大师巴菲特收购美国
    保险公司Geico,以超低价格收购，并将其扭亏为盈；另一种就是投资初创的小公司，将其做大上市或被其他公司收购。
    前者常常被成为私募资金，后者则是风险投资。
    
    

## 2. 风险的结构

- 风险投资的结构，或者说风险投资的资金是从哪里来的？专门从事风险投资的机构 和 富有的个人

- **风险投资公司的运作模式**

  - 风险投资公司扮演的是General Partner(总合伙人)，其他投资人扮演的是Limited Partner(有限合伙人)
    一笔风险投资，一般都是总合伙人拿出一笔钱，其他投资人出一定的资金，共同组成风险投资的资金，同时一般由
    总合伙人作为这笔资金的实际商业操作者，但是为了监督总合伙人，一家风险投资公司会有董事会(Board of Directors)

    或顾问委员会(Board of Advisors)

  - 不过在中国出现了一点变化，一般很少会有像美国一样出现上百个有限合伙人，一般都是由几个大的有限合伙人出资，
    甚至可能出现只有一两个投资人提供绝大部分资金的情况，而且这些投资人一般都同时担任总合伙人，并参与投资分成

  - 风险投资基金一旦进入一家公司后，就变成了该公司的股东了。

- **天使投资**

  - 所谓的天使投资就是早期的风险投资，天使投资人往往都是一些有钱人，他们很多人以前成功创办过公司，对技术很敏锐，
    又不再愿意辛辛苦苦创业了，希望出钱让别人干。



## 3. 投资过程

- ```
  我们以美国为主，举一个例子带大家了解风险投资的整个流程，但实际上任何一个成功的投资都远远比下面的案例复杂。
  ```

- **萌芽**

  - ```
    来自思科公司的工程师A和IBM的工程师B一起发明了一种无线通信的技术，当然这种技术和他们公司的核心业务无关，两人感觉这种技术很有商业价值，就写了个专利草案，花五千元请专利律师，向美国专利局递交了专利申请（关键之一:专利申请）
    两个人整天待在车库，用模拟软件MATLAB进行模拟，证明该技术可以将无线通信速度提高五十倍（关键之二:有无数量级的提高是判断一项技术是革新性的还是革命性的关键指标）
    两个人设想了很多方案，将这种技术应用到手机，计算机wifi等，并据此又申请了几项补充性专利。
    两个人带着实验结果，专利证明和简要方案四处寻求投资者，在碰壁七八次后，终于找到了思科公司早期雇员X，X自从在思科发了财，每天都与其他创业者谈论投资，对新技术眼光颇为敏锐，发现AB的新技术非常有商业价值，但是由于AB两人无法讲述清楚这种技术和具体的商业前景在哪里，建议他们找一个精通商业的人制定一个商业计划(关键之三：商业计划很重要)
    ```

- **第一次股权分配**

  - ```
    A和B找到了一个做市场和销售的朋友C，C结果市场调研，认为两人的产品确实有很大的商业价值和潜力，并制定了详细的商业计划。
    此时，迎来了第一次股权分配，本来是AB各占5成，现在结果商议，A:B:C = 4:4:2
    ```

- **天使投资**

  - ```
    A和B带着C的商业计划再次找到了X，X通过斯坦福大学的老朋友做了评估，得到了其高度的评价，X决定出资50万美元，投资AB。
    融资之后，X的要求如下：
    	1.X要成为董事会成员
    	2.ABC三人都必须从原公司离职，全心投入公司的发展，并且没有新的投资进来之前，三人的工资不得高于每月4000美元，
    	3.三人的股票必须按月，在今后的四年内逐步获得，若提前离职，则视为自动放弃之后的股票。
    	4.如有任何新的融资行为，必须通知X的天海投资团。
    	
    新公司就这样正是成立了，A任董事会主席，B和X任董事。A任总裁，B任主管技术的副总裁兼首席技术官，C任主管市场和营销的副总裁。
    三人均为公司的共同创办人。
    公司估价为200万美元，注册股票1500万股，每股0.2美元。
    经过第一轮投资后，公司的股票占比如下， 其中未分配的股票的作用：ABC三人工资很低外加聘用新员工，用来充当工资
       股东  股数     价值
    	A   27%    80万美元
    	B   27%	   80万美元
    	C   13%    40万美元
    	X   17%    50万美元
      未分配 17%    0
    ```

- **第二次融资**

  - ```
    一家风险投资公司红杉资本看中了该公司的项目，为该公司作价1500美元，即每股1美元，并投资了500万美元。
    并且委派一人到公司担任董事，同时ABC等人还答应由风险投资公司寻找一位职业经理人担任公司的正式CEO。
    目前该公司的股权如下：
       股东   股数     价值(万美元)
    	A    20%       415
    	B    20%	   410
    	C    10%       210
    	X    12%       250
     其他员工  5%       115
     红杉投资 24%	    500
      未分配  9%        0
    ```

- **第三、四次融资**

  - ```
    两年后，公司的产品研制成功，并获得了某公司的订单，同时聘请了前博通公司的COO比尔担任公司的CEO。
    但此时公司仍然没有盈利，董事会决定再一次融资，由红杉资本领头协同其他风投投资1500万美元。
    又过了两年，公司开始盈利，并最终选择上市。
    现在公司的股权如下：
      股东   股数     价值(万美元)
    	A    14%       10375
    	B    14%	   10250
    	C    7%        5220
    	X    8%        6250
     其他员工  9%       7375
     红杉投资 22%	    16250
     其他风投  5%       3750
    高盛和股民 20%      15000
     未分配	1%	   	 500
    ```

  - ```
    可以看到创始人A等人已经成为了充满传奇色彩的亿万富翁，或者千万富翁，手下的员工也有不少成为了百万富翁。
    但是包括创始人之内全体员工只持有44%的股份，一般来讲，创始人在公司上市时还有10%的股份就已经很不错了，当然也有很多投资在进入董事会后，就将创始人踢出去的情况。
    ```
