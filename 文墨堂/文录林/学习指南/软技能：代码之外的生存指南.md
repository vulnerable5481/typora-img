# 一、学习

**1、如何学习？**

- 真正学会一个东西：

  ```
  最佳实践：动手做一遍 + 能够教会别人
  【比如学习一个新知识，最直接有效的方法就是立刻动手做一遍，检验自己是否真的学会了？那就试着教会别人，对我来说就是自言自语】
  ```

- 快速理解一个东西，但没有真的学会：

  ```
  阅读一本相关的书籍or相关文章，这种方法最好的情况能帮助我们快速积累该主题的信息，但不能真正学会它
  【有时很多东西我们不需要真正学会，只是快速了解即可，这种学习方法也很有价值】
  ```

**2、方法论**

```
我需要制定一个通用的学习方法，方便快速学习新知识。
【今后学习的新知识，以前学习的知识，都要将自己总结的关于学习的方法论写在笔记的最前面！    ----2025.10.9】

			下面我们以学习数码摄影为例子，将要学习的技术称之为 N ：
1、了解全局：N是什么？
	     要完成这一步，需要对想要学习的课题做一些基础研究，通常可以通过网络搜索完成。
		例如：我们可以去网上搜索数码摄影相关的入门-进阶文章，粗略了解摄影的作用、可划分的学习模块、他人总结的方法论等
		
2、划分模块：N有哪些模块？
	     完成第一步你知道了什么是N，现在要进一步了解，进而划分出学习模块，主要学习基础模块，高级模块知道大概就行，用到再深入
		例如：我已经大致了解数码摄影，我现在划分出学习摄影的模块：
			摄像机推荐、基础入门拍摄(可继续划分)、进阶拍摄
			其中要技术对基础入门拍摄划分：	
				曝光基础、构图与拍摄技巧、对焦与测光、光线与色彩、常用拍摄场景实践、基础后期处理入门等
		注意：不要求一次学习周期就学完所有的模块，正常情况下第一次学习周期不可能学完全部，即使是基础模块也很难学完，自己取舍
3、搜集资源：用什么学N？
		  搜寻满意的学习资源：视频、书籍、文章、项目、专家、在线文档
		  
4、学习计划：怎么学N？
		  打造一份对应的学习计划，该计划必须明确以下几点：
		  					   		模块顺序：模块之间学习的优先级
		  					   		时间安排：时候阶段完成哪些模块
		  					   		
			【这份学习计划必须列在对应的笔记中】
					
---------------------------- ----------开始学习----------------------------------------------------------	
5、浅尝辄止：开始初步学习N
		   完成基础模块的学习，并在过程中不断实践
		   可以选择一个合适的时间学习高级模块
		   【必须记录相关笔记】
	      
6、深入学习：深入学习N
			如果高级模块没有学完就继续深入学习，并对之前的笔记内容进行修改完善
			在需要深入学习的时候再去深入探索高级模块
			
7、乐为人师：教导别人
		   将所学知识教授给别人，当然对我很简单，就是教给我自己
					
					
					
				
					
```

**3、番茄工作法**

```
番茄钟工作法：
	50分钟专注工作 + 10分钟休息 = 一个番茄钟 ；  4个番茄钟 -> 20~30分钟休息
	【每个人都要个性化自己的番茄钟工作时间】

为什么需要番茄钟？
	有一个大问题一直困扰着我们，总是为自己没能做更多的事情而感到内疚，好像自己玩游戏放纵就有罪恶感，因为我认为自己在浪费时间，我本
	应该将这些时间做更多的工作。
	这个问题的根源在于，你无法准确地评估每天自己都完成了多少任务，也没有为自己每天要完成多少任务设定明确的目标。你试图列出一个任务
	列表来解决这个问题，但是你发现安排总是赶不上变化，而且你不知道自己应该安排多少任务最佳。全靠主观臆想安排任务，每天能保持高效率	   学习工作的时间你不清楚，所以你不能合理安排任务。
	番茄钟的本质就是让你知道自己每天每周能高效工作多少番茄钟，通过番茄钟作为计量单位，你就知道如何合理安排任务，你知道自己每天就那     么些番茄钟可以使用，这会让你减少低效时间，高效工作；一旦你完成了工作(消耗完番茄钟)，都是自由时间，因为你知道你已经高效工作了     一整天，你有权利去放松，去享受生活。

艰难阶段：
	在最开始使用番茄钟工作法的时候，你会感到很累，因为一天保持那么长的专注时间是一件困难的事情。
	其次你得个性化自己的番茄钟，找到适合自己的N分钟工作+M分钟休息的节奏
	
注意事项：
	1、比较适合学习时间，而非工作时间 ，因为办公的时候很难保证时间是属于自己的
	2、和第一点同理，如果一天的时间大部分不属于自己，那么就不要用番茄工作法
```

**4、定额工作法**

```
定额工作法：
	按照天、月、季度、年为单位安排固定量的任务，必须严格执行

为什么需要定额工作法：
	前面我们知道了如何系统地学习(方法论)、如何保证效率(番茄工作法),现在我们需要对一些重复性的工作进行规划，我们经常会计划健身、
	阅读、写博客等，但实际上我们经常做不到这一点，如何做到呢？通过定额工作法，制定一套每天每周都要干的事情，但是一定要在我们力所能     及的范围内，不然很难坚持下来，或者生活中轻微的意外都会中止你的坚持。

一定注意：
	千万千万要小心地往你的定额工作任务表里添加任务，因为你不能反悔，不能中止，必须坚持很长一段时间(至少一年)才有取消的机会！！！
	千万要小心天这个计时单位，因为这是最难坚持的！
```





# 二、习惯

**1、减少垃圾时间**

```
从今天开始不要将时间浪费在刷短视频以及垃圾时间上，你可以刷那些视频但必须控制频率，尽量减少
```

**2、习惯**

```
1、不要再逃避了，如果你的梦想是当一个作家，那从今天开始每天养成写作的习惯    				--2025.10.9
2、应该遵循自己定下的规则，但也要保持灵活，学会从容应对偶然打破安排的情况
3、不仅是培训好习惯，也要找出坏习惯并记录
	不要着急改变坏习惯，而是要分析它为什么会出现，何时出现，以及最终如何改变
```
