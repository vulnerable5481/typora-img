# 一、自然语言处理





- 计算机是否能像人类一样处理自然语言？是也不是，目前只能通过统计学，近似达到处理效果，但实际上是无法真正理解的

  - ```
    图灵测试：
    	最早提出计算机智能的是计算机之父 阿兰·图灵，1950年他在《MIND》杂志中发表了一篇论文，该论文提出了一种验证人工智能的	  方法:人和计算机聊天，如果人无法判断聊天对象是人还是机器，说明这个机器有了智能，这就是图灵测试。
    	【最常见的就是当今计算机中有很多验证操作者是否为机器的测试】
    ```

- 早期对自然语言处理的理解：核心是理解自然语言，然而时至今日也无法做到，当今的模式是海量数据训练出的概率模型，它能在表                   .                                              现上高度逼近“理解”的效果。

  - ```
    应用层：  语音识别、机器翻译、自动问答、自动摘要
    认知层：   自然语言理解
    基础层：   句法分析、语义分析
    【实际上这是无法实现的，目前仍不能做到真正意义上的“让计算机理解自然语言”】
    ```

- 基于规则的自然语言处理 VS 基于统计的自然语言处理

  - 在二十世纪七十年代之前基本都是基于规则来进行自然语言处理，什么是基于规则？就是根据人类的各种语法推演的处理模型
    但局限很大，一个简单的句子落实到代码和模型中是极其复杂的，且规则之间还会产生冲突，同时具有时限性。可以说这时期整个人工智能的发展都是相当失败的
  - 之后统计学的出现，让人工智能焕然一新，这个原理较为通俗，故省略
