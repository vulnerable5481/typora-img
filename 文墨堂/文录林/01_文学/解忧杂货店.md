# 1、介绍篇

## 1.1、故事梗概

```
开篇：
	三个小偷小摸都失败的流浪贼躲到了一家旧杂货店，令人意外的是这家破旧无人的杂货店有着连接过去的牛奶信箱，信箱中静静躺着一封崭新的信，一场关于救赎的故事就此展开。

1、《运动少女与病危男友》
	月兔是一位在某些运动中成绩斐然的运动员，但在奥运会备选竞赛期间男友身患癌症时日不多，月兔宁愿放弃奥运会选拔也想陪伴男友最后一段时光，但男友却希望月兔专心备赛不要误了前程，在内心的煎熬与纠结之后，月兔向传闻能解人忧虑的杂货店悄悄递了一份信。小偷三人组通过间接询问月兔喜爱的电影与音乐得知了她处在四十多年前的时空，而她心心念念的奥运会则会因为日本抵制莫斯科而取消，因此三人强烈要求月兔放弃奥运会陪伴男友，不过月兔还是参与了选拔训练，最终遗憾落选，男友也在期间离去，不过她在半年后的信中倾诉了内心，其实自己认为已经达到了能力的上限，难以进步，又刚好男友生病，为了逃避失败，希望自己有一个合适的逃避理由。
【第一篇主要是讲述了杂货店背景和小偷三人组，无亮点】

2、《鱼店音乐人》
	我来到了一家孤儿院做公益演出，演奏了的多个曲子吸引了孩子们的目光，但角落里的一个小女孩始终没有在意自己的演出，直到自己演奏了结尾才会出现的曲子，终于吸引到了小女孩。演奏之后，在食堂偶遇小女孩，她主动询问自己最后演奏的是什么曲子，她从来没有听过，我说那是自己原创的，当然没人会听过，不过令我没想到的是她居然能哼唱下来自己演奏的完整曲子。
	我自小热爱音乐，但家里想要我继承几辈的家业----一个鱼店，为了父母不再阻拦，初中时期就励志学习，父母也给自己买了一把旧吉他，每周末都会练习一整天，尽管如此自己学习也没有拉下，如愿考上了当地最好的一所高中，随后进入了一所大学，为了不让父母唠叨选择了经济学院，但自己很快意识到大学生活是如此如此浪费时间，最后由于沉迷音乐，荒废学业一再留级，后来就从学校退学了，自己也因此与家里决裂。在社会上自己的音乐天赋没人赏识，只能平庸地活着，直到一天，妹妹电话通知说奶奶离世了，自己明白也该回去一趟了。回到家中，惊讶地发现自己的房间居然还是之前的样子，没有什么改变，家里只有妹妹在等着自己，爸妈都在为奶奶的离世忙碌。简单收拾一下，便去灵堂，遇到了一些亲人，他们得知自己居然退学后就开始不断唠叨着，不过让我惊讶的是爸妈居然没把这件事告诉别人。母亲依然是从前温柔的样子，父亲苍老了很多，听妈说还有了心脏病，身体经常不适，但一见到阔别已久的父亲依然感到很大的压力，父亲的态度依然是从前那副样子，后面父亲独自在灵堂亲手把祖传的杀鱼刀放在灵柩中，嘴里念叨着什么，在父亲发现自己之前，我悄悄离开。自从回到家后，看到母亲白了些许的头发，父亲不断苍老的脸和日渐衰落且装作坚强的样子，自己在音乐路上也没有闯出名堂，也许自己该认清现实，把音乐当当爱好，当一个鱼店音乐人也不错。来到外面，碰到一个长相端正，手臂壮实，看起来像是运动员的女生把一封信放到了杂货店，那家杂货店自己小时候也经常写信咨询烦恼，不过大都是考试怎么提分，如何买到好吃的等这种问题。也许是心情烦闷，自己也向着从前那样写了一封信投到信箱中，没想到很快便收到了回复，信中说自己三年了都没有混出名堂，还是早点继承家里的卖鱼店比较好，看了信自己当场觉得恼火，随后又写了一封信，希望对方与自己正式见面，不过被拒绝了，在察觉到杂货店中好像有人存在，自己便把独创的那首曲子演奏出来，没想到对方听后居然一转态度，在后来最后一封信中说到，你的曲子在将来会拯救别人，请坚持下去，直到生命的最后一刻。也许是看到有人被自己的曲子打动了吧，此后自己竟真的坚持了下去，随后还出了自己的CD---《重生》，也就是自己原创的曲子，可惜销量惨淡。
	做完公益演出之后，却发现院子居然着火了，我赶忙过去，才发现那个小女孩站在门前想要进去，我及时拉住了她，却才得知她的弟弟还在里面，我让她赶紧去叫大人灭火，自己便冲了进去，之前与女孩交谈知道她们住在三楼，我一路爬上去终于在房间里找到了昏迷的小男孩，我抱起他向外面跑去，但是火势越来越大，来路已然被火海吞没，我把孩子抱在沾水的衣服后便向外冲去。
	演唱会开始了，最近几年火热的国民天才音乐少女站在舞台中心，歌迷们都不再喧哗，因为他们知道这是少女每次演奏会的最后一首曲子，她在台上说，这是自己唯一的亲人弟弟的救命恩人所留下来的曲子，歌名为《重生》，谨以此曲，纪念离去之人。
【第二篇还是非常nice的】
```



# 2、Skill

## 2.1 东野叙事风

```
题外话：7.27，网上已经官宣东野大叔去世了，令人感慨，自己还是相当喜欢他的作品。

1、倒叙
	东野大叔非常喜欢使用倒叙，尤其是在刚开始什么都不知道的情况下，一点一点抽丝剥茧，这种叙事风很适合社会派推理

2、多端叙事
	东野大叔基本会把一个章节都分成多个小篇章，一般前后没有特别直接的连接

3、伏笔回收，结尾留白
	伏笔回收，但是结局经常戛然而止，留下无穷的遐想
```
