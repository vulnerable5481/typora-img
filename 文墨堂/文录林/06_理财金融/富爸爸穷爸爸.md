# 1、核心观点

```
第一部分：思想启蒙
	第一章节，富人不为钱工作，核心内容就是告诉你工作是为了更好的认识社会、积累原始资本和充分的学习时间，如果你工作只是为了单纯的薪资那么你一生都很难摆脱财产问题，主要是思想启蒙，在之前与发小的创业聊天中，这一点我已经很熟悉了，不再赘述。
	【阅读完本章，则是坚定了自己的信念】

第二部分：财务知识
	第二章节，为什么要学习财务知识，核心内容就是告诉你要主动学习金融、财务知识，理论知识的积累和原始资金的积累也是一样的重要。你不可能指望一个没有财务和金融知识的人只是因为想要致富他就真的梦想成真了，肯定是要学习相关知识的。
	【阅读完本章，发现目前自己欠缺财务、金融知识，后续需要专门学习！】

第三部分：资产与负债
	第三章节，关注自己的事业，这是大家最关心的富人是如何摆脱财务问题的？核心内容就是理解两个概念：资产与负债————————资产就是将钱放进你口袋的东西，负债就是把钱拿出你口袋的东西。比如说房子对于很多人都是负债，它不是你的资产，资产是让钱为你工作的，当你睡觉的时候也能赚钱，你就真的做到了让钱为你工作，而不是为钱而工作。如何创造资产，比如我们在坚持自己职业的同时，可以去发展一些副业，比如在拥有一定的金融知识可以尝试轻型创业、尝试了解股市等钱的游戏，当你的资产逐渐形成规模，最终超过了工资时，当你睡觉的时候也能让钱工作的时候你就摆脱了世俗工作，你可以开始为自己工作。
	【阅读完本章，真的是眼前一亮，资产与负债的概念不新，但是非常准确地把大家知道但模糊的概念清晰化！
	  同时自己也是第一次下定决心要发展自己的副业！！！！】
	
第四部分：致富的进阶方法
	第四章节，纳税与公司的力量，当你拥有了自己的资产，或者拥有了原始资金和财务知识，已经做好摆脱世俗工作的准备时，你应该学习了解纳税与公司的力量，纳税最开始是用来惩罚富人和为政府扩大收入的工具，但逐渐纳税扩散到了中产阶级和穷人，但是现在富人反而纳税要比普通人少很多，包括通过公司进行合理避税操作，这些我之前就有所耳闻，已经了解过了。
	【阅读完本章对纳税与公司对个人的帮助有了更清晰的认识】

第五部分：作者例子
	第五章节，富人的投资，主要是用作者个人的投资经历举一个例子，还是强调一些概念，比如
	1、勇气是一部分人走在时代前沿的方法；
	2、投资要有自己的财富知识，不然守不住自己认知外的财富；不鼓吹大家盲目投资，要有自己的判断
	3、要终身学习，很多人离开学校后就停止了自主学习
	【这章还是强调为主：勇气、知识、终身学习】

第六部分：多种技能的重要性与克服恶习
	第六、七章节主要是强调了营销、沟通销售等几种技能对于积累财富的重要性；列举了克服恐惧、克服懒惰、克服乱花钱等恶习，这里的恐惧指的是不要害怕失败，有可靠的方案就要勇于尝试，初期的失败反而是快速成长的经验；克服懒惰，有的人总是看着很忙碌，或忙于生活，或忙于工作，但这些都很难让你有所受益，当你开始行动的时候就应该知道哪些事情是迫切的；克服乱花钱，指的是富人总是将收入先支付资产，剩下的支付自己。
	【阅读完本章我意识到自己需要学习一下市场营销、销售、沟通等技能，通过阅读、专门搜索文章等方式进行；克服恶习】

第七部分：开始行动
	本章我认为核心思想为：
		1、强大的精神驱动力，找到一个超越现实的理由，比如你不想将一生的时间浪费在重复的工作上，渴望自由、探索与创作等，如果没有强大的驱动力，想要实现财富自由是一件很艰难的事情
		2、开始行动在于每一天，财富初期的积累尤其依靠每一天的积累
		3、掌握一种投资模式，比如房地产、股票等，先深耕一个模式，后面拓展多个模式
		4、持续学习
	【后面几章阅读得比较仓促，不过整本书的收获相当丰富！】
```

# 3、推荐

```
  假如让我给别人推荐这本书，我该如何回答呢？
  首先这本书的受众我认为更适合一些思想上未解放，仍然没有从传统工作观念中转变过来的人，同样也适合有一些渴望财富自由有一定思考但是没有实践，脑海中尚未建立清晰的认知的人，那么这本书决定很适合你，会让你得到思想启蒙，对资产有一定的了解，产生动力。
  这本书并没有直接告诉我们要怎么快速实现财富自由，而是从三个部分对资产创造现金流摆脱工作实现自由进行剖析。第一，思想启蒙，让你知道盲目的工作不能摆脱负债；第二，理论知识，你需要掌握一定的理论知识，且要持续地学习；第三，一个核心概念，资产与负债；第四，其他部分主要就是进阶知识科普、作者本人经历等。
```
