# 导论

```
1、什么是哲学？
   人类企图系统地研究我们这个经验的最基本结构，以便达到概念上尽可能清晰、经验上尽可能被确证和理性上尽可能融贯的信念。
   
2、哲学的三大基本标准
   概念清晰性：概念和语词是观念的载体，哲学是逻辑清晰的观念。
   经验确证性：哲学必须经得起考验，大型的哲学理念不会被单一的经验支持或反驳。
   理性融贯性：认识到某种哲学可能没有明显逻辑错误，但是它的主张仍可能没有很好地结合在一起。
             比如有些哲学家认为我们的所有行为和选择被我们不受控制的心理原因锁决定，但是我们仍要在道德上对自己的行为负责
             比如有神论者坚持上帝是慈爱和全能的，但同时无辜的人也在世界上受苦。
```

```
理解题

1、在何种程度上我们以得感冒的方式获得我们的观念？这为什么是糟糕的？学习哲学史可以怎样对此做出补救？
   ① 在学校学习到的知识/观念这不算是以得感冒的方式获取，当我们无意间的阅读、与他人的辩论、意外事件学习到的事物、脑海中闪过的过往的记忆碎片，这些我认为是以感冒的方式获取的观念。也就是通过无意识获取的观念就是“感冒”。
   ② 因为这种无意识获取到的观念可能是错误，甚至引发灾难。
   ③ 学习哲学史，是学习哲学的第一课，在此阶段我们会以时间的维度遍历一遍哲学，势必会接触各种哲学，其中就包含过去无意识接触到，过去无意识的观念，在此刻都将具象化，我们得到一次重新选择的机会。
   
2、哲学为什么像是一种关系？
	① 哲学是庞大的。从古至今有数不清的哲学家，其中诞生了无数种哲学，它们之间有着紧密相连的关系，或是互相依赖，或是互相矛盾。
	② 哲学的本质。其本质就是人类对过往问题的进一步总结与思考，这之间必然存在前后的关系。

3、一个论证要问的两个问题是什么？
	① 论证的前提是否为真？
	② 前提为论证提供了怎样的支持？

4、什么使得一个问题变成一个“哲学问题”？
	所有问题都可以是哲学问题，但是已经被广泛采纳认同已被解决的问题不算哲学问题，因为大部分哲学都有合理且互相没有明显冲突的解释，
	问题已经得到初步解决，问题不再是问题，而变成了一种求同存异的观念。
	如果多个哲学派系在一个问题有明显的分歧与冲突，且长期无法得到解决，这个问题就是一个哲学问题。
```





# 一、古代



## 1. 希腊文化背景：从诗到哲学

**诗歌的角色**

```
  哲学的故事始于诗歌。诗人在古希腊占据核心地位。诗人绝不只是用华丽语言描绘神话故事，他们用诗歌保存、记录、发展所处时代的文化。
  古希腊诗歌通过诸神解释世界。每一个希腊神都代表着生活中的一个领域，如狩猎、农业、贸易、爱情、战争、死亡等，这些神话都是那个时代人们力图用熟悉的、可观察的事物解释不熟悉的、神秘的东西。
```

**荷马**

```
  要确定哲学的阶段，需要考察一下最重要的希腊诗人荷马。荷马的诗对宇宙的性质提供了几点广泛的构想。
  第一、自然中发现的规律(例如，季节交替)都是诸神长期的意图和目标，但是诸神是冲动任性、变化无常的，例如突然的一场暴雨、一场毁灭的海啸就是海神波塞冬引起的，不过这不是诸神长期的意图，所以是短暂、无规律的。
  第二、荷马的诸神与基督教的神有着天壤之别。荷马的诸神是具有人性的，有着自己的人格，他们不是万能的，会被其他的神打败，也会被命运的力量束缚，此处的命运也可以理解为一种自然规律。
  
  荷马构造的诸神世界可以简单笼统地概括为：
  	① 世界普遍的自然规律是诸神的长期意图与目标；世界的有些事件是由于诸神的反复无常/某些神圣行动导致的
  	② 世界当中存在着随机的因素，因而有些事件是没有任何目的
  	③ 命运凌驾于诸神和人之上，命运是一种力量与自然规则，有时会以命运之神的形式出现
  	
  尽管荷马的宇宙图景很粗糙，但却是理论思想的种子，但种子突破神话的束缚，自然结出哲学的果实。
```

**西方哲学的诞生**

```
传统上认为哲学诞生于公元前六世纪，随着泰勒斯及其他早期人物的出现而诞生的。
```

**古典哲学纲要**

```
古典哲学始于泰勒斯，终于中世纪，期间有多个阶段。

1、宇宙学时期（公元前585-公元前5世纪 --第二章
   关注外部自然、想要认识根本上实在的东西
   
2、人类学时期  -- 第三章
   关注以人为核心的问题、探寻有关知识与操行的问题
   (a)智者派(公元前5世纪)--怀疑的、实践的
   (b)苏格拉底(公元前470-399)---关注发现客观的知识和价值
   
3、体系化时期   -- 第四、五章
   关注发展一种综合的哲学体系、首次提出了哲学的全部基本问题
   (a)柏拉图(公元前427-347)
   (b)亚里士多德(公元前384-322)

4、亚里士多德之后/希腊化 - 罗马时期的哲学(公元前320-公元529年) --第六章
	关注个体主义、实践的问题
	形而上学的关切从属于伦理学的关切
	犬儒主义、伊壁鸠鲁主义、斯多亚主义、怀疑主义、新柏拉图主义
```



## 2.苏格拉底之前的希腊哲学

### ① 米利都学派

**泰勒斯**

```
  泰勒斯，生平可能在公元前624-524年，他的母邦米利都是位于小亚细亚西海岸爱奥尼亚地区的一个繁荣的希腊海港，由于其地理位置，泰勒斯及其另外两个继承者都被称之为米利都学派的哲学家。泰勒斯是世界上第一个预言日食的人。他还发明了很多航海工具与技术，有很多技术成就。这些早期科学家/哲学家都致力于探求普遍规律和某个现象的合理解释，这一阶段科学与哲学甚至很多学科都是一体的。技术成就只是一部分，真正让他名留青史的是他发动了一场有关事物的终极本质的争论，这场争论至今都在持续。

1、泰勒斯的问题
   寻找世界万物最基础的单元。我们的世界有各种事物：动物、沙子、星星、太阳、暴风雨等，是什么把这一切统一起来？是什么基础的“材料”构成了我们熟悉的世界中的一切事物？终极的实在是什么？这构成了前苏格拉底哲学家们的首要任务
   
2、泰勒斯的回答
	泰勒斯认为：水是万物的本源。因为水对于生命来说至关重要，不仅如此水还可以转化为一切，比如水的固液气三态的转换。

3、变化问题
	泰勒斯的问题可以转变成对“永恒与变化”、“存在和生成”的问题

4、泰勒斯的意义
	我们可以把泰勒斯的影响和贡献总结为以下几点
	第一、一元论的早期例子：实在是由一个原则（水）而得到说明的，泰勒斯的这种主张是一种形而上学一元论的早期例子
	第二、泰勒斯提出作为一切现象之基础的终极实体是什么，这个发问开启了漫长的哲学交锋
	第三、泰勒斯的回答，泰勒斯没有简单地给出答案，而是提出了一个由多个前提支撑，允许别人争论、校验的理论，这便是一种哲学形式
```

**阿那可西曼德**

```
  阿那可西曼德，生平大概是在公元前610-545年，他比泰勒年轻一些，很可能是泰勒斯的学生。
  
1、阿那可西曼德的问题
	依然是其老师的问题

2、阿那可西曼德的回答
	阿那可西曼德首先否定了老师泰勒斯的答案，不止是水，还有火、土、气等元素，都是我们在世界发现的一种元素，显然万物的基础元素不会是这些常见元素。他认为终极的存在一定是永恒不灭的源泉，一切事物都来自于它，又复归于它。它不是一个具象的事物，不受时间和数量的限制，也就是说在时间和数量上都是无限的。它是湿的吗？阿那可西曼德会说不是，因为倘若如此，它就不可能产生干这个属性。它是冷的吗？阿那可西曼德会说不是，因为倘若如此，它就不可能产生热这个属性。所以它一定是无法被界定的，没有特定属性的事物。
	
3、变化问题
	阿那可西曼德在其老师的基础上继续发展，将问题向着更加抽象的模式发展，他认为一切之基础是无法被界定的存在，
	阿那可西曼德提出了相冲突的对立面，他说世界是由相冲突的对立面组成的，一天分为白天与黑夜，冷与热、湿与干、太阳与月亮，但他们都一定来源于一种更加根本的存在，正是从这个原初的实体分离、又复归的过程形成了我们所认识的自然规律。最初，一切事物都是它的一部分，不同的性质从中分离，就像是离心机里的微粒从溶液中分离，这种分离似的旋转运动说明了星球最初是如何动起来的。通过这个过程，产生了所有的对立面，冷与湿的结合产生了大地与云朵、热与冷的结合产生了气、温暖与潮湿之中诞生了生命......有趣的是，阿那可西曼德对世界的说明里包含着朴素的演化论，他主张，一切生命---包括人类---最初都来自海洋。
	阿那可西曼德对“大地立于什么之上”这个古老的问题，给出了一个非常现代的答案。他认为大地立于虚无之上。由于大地是球形宇宙的中心，所有方向的引力都是一样的，阿那可西曼德认识到，宇宙中不存在绝对的上与下。
	
4、阿那可西曼德的意义
	阿那可西曼德将问题向着更加抽象的方向发展，问题的答案可能是无法界定的。某种意义上来说，确实很哲学
	阿那可西曼德具有哲学批判思想，对其老师泰勒斯的理论进行了合理的哲学批判与深思。
```

**阿那可西美尼**

```
  阿那可西美尼，生平可能比阿那可西曼德还要年轻，大约在公元前545年左右。

1、阿那可西美尼的问题
	依然是泰勒斯的问题

2、阿那可西美尼的回答
	他认可阿那可西曼德的理念，但认为对方的回答是不充分的，既然存在着基本的实体，如果我们知道有这么一种东西，那一定能够清晰描述出来。他认为世界万物最基本的实体就是气。第一、气比水更具有普遍性，更可能是最基本的实体。第二、气是整个自然的核心，它是火存在的必要条件，水和土里都能发现气。第三、气能够自我支撑，水没有气的支撑就会落下，所以水不可能支撑大地，气则能够支撑大地立起来。第四、气维持着生命，阿那可西美尼相信气就是人的灵魂，人的死亡就是呼出最后一口气，气(也就是灵魂)离开了我们的身体。
	
3、变化问题

4、阿那可西美尼的意义
	就像是阿那可西美尼认为的一样，如果真的存在终极的实在，那它一定是清晰可见的，而不是像阿那可西曼德认为的那样虚无，无法界定。
```

### ② 毕达哥拉斯

```
   毕达哥拉斯，生平约为公元前570-495年，他是一个哲学家、数学家和宗教神秘主义者，他发明了毕达哥拉斯定理，俗称“勾股定理”。他不仅在数学方面成就卓越，还是一个哲学家，是目前已知最早的第一个自称哲学家的人，哲学家，在那时的意思是“爱智慧的人”。此外，他还是一个宗教神秘主义者，他创建了一个既接纳女性又接纳男性的宗教团队，在这里，他是神，通过口头教导和秘密宣誓来传教。

1、哲学与救赎
	对于毕达哥拉斯学派来说，宗教的目的是净化。他们相信灵魂是永恒不灭的，死后会从一具身体来到另一具身体，甚至是一具动物的身体，想要得到真正的“解脱”，摆脱这永恒的轮回，需要我们在现实中进行各种仪式去净化灵魂，其仪式主要就是禁欲主义的生活，充满了众多的禁忌和饮食限制。该教会既作为一个数学学派而活动，也作为一个修道会而活动，延续了两百多年。

2、实在是数学的
	对于毕达哥拉斯学派来说，宇宙存在着一种秩序，而数学就能揭示秩序，因此数是实在的根基。从数学中的点出发，点产生了线，线又构成了平面图形，而多个面则形成了立体。因此从数学出发，我们可以尝试理解宇宙。再比如说，音乐之中就隐藏了宇宙的数学性质的线索，在希腊音乐中，三个主要的音程是八度、四度和五度，他们的音调之间存在着确切的数学比例。如果数是音的基础，那么它也可能是其他一切的基础。天体之间的距离就如同音乐中的音调比一样存在比例，毕达哥拉斯学派称之为“天均”。
	他们还认为如果一个事物中能像定准了调的乐器那样和谐地活动，那么该物体就是健康的，正常的。因此，天文学、音乐、医学以及一切都由数值比例掌控。

3、形而上学二元论
	毕达哥拉斯学派还认为世界受着秩序和无序这两者持续不断的冲突的支配。他们将至总结为：秩序与无序、有限与无限、奇与偶、一与多、静与动、雄与雌、善与恶、明与暗、直与曲、正方与长方等。
	这种一方等同于善，另一方就等同于恶，因此也叫道德二元论。
	
4、意义
	① 毕达哥拉斯学派将自然视作一个巨大的数学秩序，这是一个迷人的成就。
	② 科学与哲学的完美融合
	③ 哲学开始着重关注个人的伦理
```

### ③ 赫拉克利特

```
  赫拉克利特，生平约为公元前540-480之间，因为地理位置的因素，他非常熟悉我们前面聊过的哲学家。他被称为“晦涩的哲学家”、“晦涩的赫拉克利特”。他的很多思想著作都很晦涩难懂，这违反了概念清晰性，但他也代表思想史的一个有趣阶段。
  赫拉克利特并不是一个和蔼可亲的人，他有着一颗自负、傲慢、蔑视人的头脑，他用它创造了一系列批判性的、独断的名言。虽然他的态度很贵族化，但是他拒绝了社会给他的一切荣誉，比如本可继承的宗教和政治权位。他对人的苛刻态度和完全的蔑视，注定他孤独的一生，他认为，大多数人比牲口好不了哪去。他终其一生都过着孤独的隐居生活，但是他的思想与著作名言激起了相当多的辩论。
  
1、作为变化与冲突的实在
	米利都学派寻找的是物质上的实在，他们认为世界虽然有在变化，但一切变化的现象存在永恒不变的基础性“材料”。但赫拉克利特批判性地认为世界是变化的，并指出我们所谈论的一切“对象”实际上都是诸多过程的集合。比如天气，当我们讨论天气的时候，它不是单一的对象，而是诸多过程的集合，它是由许多各不相同、相互作用的过程的集合：高压与低压、湿度、温度、水的三态、风向、风速、密度......
	赫拉克利特的一句名言：“你不可能两次踏进同一条河流”。河流永远在流淌，在变化，你现在踏进的河流，下一次踏进就不再是同一条河流。我们人类也是如此，几年前的你，与现在有着巨大的变化，价值观、长相、身体、性格、经历都截然不同，在某种意义上，你们不再是同一个人。

2、逻各斯 
	逻各斯，Logos，古希腊语：λόγος，是一个古希腊哲学的核心词汇，它的含义非常丰富，也是哲学史上最重要、最复杂的概念之一。在古希腊语中，λόγος（Logos） 最初的意思是：“言语”、“话语”、“理性”、“道理”、“规律”、“理则”、“比例”等。
	赫拉克利特是第一个把Logos提升为“宇宙法则”的哲学家。
	赫拉克利特认为实在是变化的，一切事物也都在变化，但是变化本身这一条规则/秩序是永恒的。这个永恒不变的规则就是Logos

3、对立面的统一
	赫拉克利特认为尽管世界有很多对立面，但按照之前说过的，一切“对象”都是诸多过程的集合，按照持续性的观点，对立面很多时候都是统一的，比如一天分为白天与黑夜，尽管两者是对立的，但是又都归属于一天。
```

### ④ 巴门尼德

```
  巴门尼德，生平大约公元前450年之后，与赫拉克利特生活在同一个时代，柏拉图的记载中，巴门尼德曾经遇到过少年苏格拉底。
  巴门尼德的思想似乎是不大可能的，甚至荒谬的。但他通过逻辑去证明自己的思想，这种强推理风格在此之前是少有的，尽管他的结论有些不可信，但是推理确实很严谨。他的推理风格使得他在哲学的发展中很有影响。
  
1、实在是不变的
	巴门尼德的思想可以提炼为以下内容：存在者存在，除了存在者之外，没有任何别的东西。
	这很难辩驳，目前来看这句话没有问题，巴门尼德根据这一简单的内容推导出了一些匪夷所思的结论。
	（1）任何我们能够思考或言说的东西要么存在，要么不存在
	（2）不存在的东西就是无
	（3）我们不能思考或言说无
	（4）因此，我们不能思考或言说不存在的东西
	（5）因此，任何我们能够思考或言说的东西都存在
	第一个前提提供了两个互斥的选项，第二个前提是根据定义而为真的，目前都没有任何问题。
	但是第三个前提和第四个前提颇具争议，我们不能思考或言说无，为什么不能这样做？巴门尼德认为思考不存在的东西没有任何意义，如果我纯粹地思考无，那么我的思想就会没有任何内容。那么第四个前提呢，因此就不去思考或言说不存在的东西，但是思考不存在的东西是完全可能的。例如，我可以思考火星上的一个汉堡，这是不存在的，但是巴门尼德会说这不是思考无，是思考火星与汉堡，而这两者都是存在的。
	根据上面最初的论述，巴门尼德还得到了多个逻辑后承。此处只简单列举几条。
	1、存在是非创造的
		巴门尼德使用后来人们所知的“因果性原则”。
		如果存在始于某一个点，或是被创造出来的，那么它(a)要么来自某物(b)要么来自无。如果存在就是存在的东西，那么(a)就不可能成立
		因为存在不可能由于其他原因而存在起来。此外，存在不可能来自无，因为无不存在，不能导致任何事物，因此(b)也不成立。
	2、存在是不变的、不灭的
		存在的变化只有不存在，一个事物要么存在要么不存在，如果存在发生了变化，就意味着存在变成了不存在，也就是变成了无。但是前面		已经说了，存在就是存在，存在之外的就是无，非存在不可能存在，所以存在不可能变成不存在的，存在不会变成无，so存在不变。
		【存在可以是曾经存在，但是后面又不存在，存在是可以变化的】

2、巴门尼德的捍卫者-芝诺
	巴门尼德因为自己的思想遭到了很多人的嘲笑，但是有一个小自己二十多岁的门徒，是个非常有能力的捍卫者，他采取的主要策略就是先采纳反
	对者们的意见，从他们的立场出发得到一个或多个结论。然而，这些结论要么互相矛盾要么显然荒谬，这就是所谓的归谬法。芝诺的这些论证被
	很多二十世纪不计其数的数学家和哲学家进行探讨，企图对它们一探究竟。
	下面让我们看看芝诺的论证艺术。
	1、反对多的悖论
		如果有一个长1.8米的木头，我们每次锯下其总长度的一半，这根木头就可以无限地切割。但按照反对者的论证，任何一个对象都不可能		 是无限的，都必定有特定的大小，不可能被无限地分割为多个部分。
	2、运动悖论
		一个人从A跑到B，每次都跑全称的一半，这样他永远也抵达不到B点。这与我们的信念相反，这样的运动不可能有任何合理的意义。

	显然芝诺的论证必然有着错误，但是这错误具体是什么，很多人都难以指出。近现代有很多人为此做着努力，比如数学家格奥尔格关于无限集合
	的革命性工作，正是为了解决上述的一些悖论。
	巴门尼德和芝诺都认为实在是不变的，宇宙是不变的，变化是一种幻觉。
	
3、意义
	① 他们的思想和理念是反直觉的，与大众背道相驰，但这种反直觉的理念往往是划时代的，具有前瞻性的，是科技/思想革命的钥匙。他们愿意放弃显而易见的知识，去追寻自己的理念。
	② 他们对语词和概念中蕴含的逻辑推理进行了反思与总结，并应用到了实际。
	③ 他们用严格的逻辑推理，要求后世的人们用通用严谨的推理去反驳他们，比如后来的苏格拉底、亚里士多德都“被迫”严谨地处理这些遗留的问题，这些悖论，即使知道是错的，也要严格推理其错误的原因，这激发了人们艰深的思考。
```

### ⑥ 原子论者

```
  通常我们将德谟克利特作为原子主义者的思想来源，他不仅仅是哲学家，还是出色的物理学家、伦理学、历史学家。
  
1、存在
	在原子主义者看来，两个原则解释了实在：原子与虚空。他们把虚空或空的空间当做了存在的一部分，他们是在宣称，不存在者是存在的。
	原子有几种特性。
	① 它们是不可分的，是永恒的，是不变的。然而它们在数量上是无限的（空间的无限延展允许这一点）
	② 原子存在着量的区别，它们有着不同的大小和形状，但它们是中性的（没有气味、颜色、温度、滋味）

2、变化
	原子主义者认为变化其实是原子分离的结果。
	① 不存在绝对的上与下，因此，运动是没有方向的。
	② 由此推出，原子没有绝对意义上的重量
	③ 原子的运动是永恒的。  亚里士多德曾经抱怨这一点，说原子论者懒惰地搁置了运动的起源这个问题

3、现实世界
	我们所看到的世界都可以用原子论解释。
	① 原子的运动及其几何属性造成了各种各样的相互作用与结合
	② 这些作用与结合造成了我们感官经验中所发现的性质，比如气味、颜色、滋味、冷热等
	  例如：有着粗糙表面的原子与有挂钩的原子相结合，就形成了固体；光滑的球形原子形成了水等液体；
	       有刺钩的原子构成了苦，当我们吃下苦瓜，这些有刺钩的原子刺激着我们嘴部的原子，形成了苦的味道；
	③ 知觉流射理论：来自对象的原子飞离对象，碰撞我们的感觉器官，这一冲击的运动传递给了我们的灵魂原子。

4、意义
	原子主义者这种机械的物质主义不足以解释世界，但是在16世纪、17世纪作为科学的基础再次获得新生，直到19世纪都几乎保持不变，
	因此，至少等我们考察过原子主义后来的这些方案之后，才会对之进行评价。
```



## 3.怀疑主义

### ① 智者

```
  在公元前5世纪之前，一方面，哲学家们一直在辩论物理自然的传统问题，另一方面哲学史上一个关键的转折点也浮现了出来。想要说清楚这个转折点，我们需要先了解一下当时的时代背景。
  公元前5世纪，希腊正处于古典时代的黄金期，政治上，出现了新兴发展的雅典民主政治，经济、文化(尤其是是哲学)、诗歌、戏剧等都取得了丰硕的成果。但是随着社会和政治的变革，人们的观念逐渐改变，不再尊重雅典的法律、宗教和习俗。尤其是伯罗奔尼撒战争之后，旧理念不断瓦解。
  在哲学界，一场哲学喧嚣也随之开始，哲学家们对实在的本性众说纷纭，怀疑主义开始流行，怀疑主义认为不可能认识到真相。这使得人们对形而上学问题失去了兴趣，取而代之的，是另一种日益增长的兴趣，对个人及文化更加实际的关切。
  在这场哲学喧嚣中，我们将卷入喧嚣的一群教育者，称之为“智者”，最初这是褒义词，但是苏格拉底与智者发生了争执后，这个词逐渐成为贬义，柏拉图说“智者是贩卖精神商品的店主”，亚里士多德说“智者是欺诈者，他们只是在教导人们，使糟糕的论证看起来好些的技巧”。在最糟糕的形式中，我们可以将智者派系的核心思想总结为：怀疑主义与成功

1、怀疑主义
	智者们认为，真知识是无法被获得的。
	当我们回顾公元前5世纪短暂的哲学史，就能发现成堆的矛盾：泰勒斯说水是最基础的元素，他的学生很快就进行反驳并提出最基础的实在是无法界定的，很快又有人说是可以界定的，气是最基础的元素；又比如巴门尼德说实在是不变的、是永恒的，赫拉克利特却说实在是变化的。好像没有人能够统一真理，大家所认识到的真理都只是相对的一面。因此，智者们认为一切真理都是相对的，一切价值观和标准也是相对的。“真理“、”正义“、道德的善”、“道德的恶”这些都是什么？智者认为这都是我们发出的声音，不同的人自然有不同的理解，也就出现了矛盾。

2、成功
	智者们认为，获得成功才是生活的目的
	如果真理/知识是不可能获得的，那么我们不必耗费时间精力去探究它，因为终究徒劳无获，我们要做的，只是让自己努力过活就行了。
	智者们教导说，对于一个观念，我们不需要说它是对还是错，而是问“我赞同/反对它对我有益吗？”; 对于一个行为，我们不需要说它是正当的还是邪恶的，而要问“做出这个行为对我的有益吗”。

3、一个重要的问题
	对于智者们有一个重要的问题：the difference between physics and nomos
	physics(物理)指的就是自然规律，英文意思是物理，而物理不正是一门总结自然规律的学科吗。
	nomos(人为)指的是基于人的习惯或习俗的东西
	例如下面的两个例子：
	中国人习惯用筷子吃饭，欧洲人习惯用刀叉吃饭，印度人喜欢手抓饭，不同的习惯这就是nomos，都需要食物维持生命就是physics;
	道德仅仅是一个人为的问题还是自然规律？若是自然规律应该能在自然中找到基础，智者们都认为传统的道德是基于人为或风俗。对于保守派的智者来说，应该尊重传统的道德，这是获取成功的条件；对于一些玩世不恭的智者来说，我们应该口头上尝尝高调，私下不能让它束缚我们的手脚。

4、早期智者与晚期智者
	早期智者，倾向于保守，在我们无法认识真理的情况下，我们应该坚守我们社会的风俗。
	晚期智者，倾向于激进，人为风俗与自然规律是冲突的，我们最好遵从自然。
	
5、意义
	① 比起前面提到的宇宙论者们，智者更关注人文问题，关注人类事务问题，拓展了哲学的范围，脱离了单纯的宇宙论。
	② 智者提出了很多在前辈们被忽略的问题，这激励了后世人们的思考，尽管是对他们的批判，也是一种思想的进步。
	③ 智者与他们的对手苏格拉底展开的辩论，代表了一个过渡阶段，之后柏拉图、亚里士多德则是体系化哲学。
```

### ② 著名智者

```
1、普罗泰格拉
	他是最著名的智者，生平约为公元前5世纪，可能死于公元前420年。
	① 激进的个体主义+相对主义：他反驳了之前所有的宇宙论者们(比如巴门尼德)，他认为之前即使互为矛盾的理念也都是真的，因为每个人的真					        理都是相对，没有对错。因此，一切信念都是真的。
	② 我们都是通过知觉与世界接触的：诸如一阵风，我觉得是凉的，你觉得是热的，没有对错，只是不同的个体相对感觉不同而已。
	③ 作为早期智者，他很尊重人为风俗。他认为无法认识真理的情况下，我们应该尊重风俗，尊重这个唯一用以指导生活的东西。

2、安提丰
	他是晚期智者，认为我们应该服从自然规律，我们自然地去寻求对自己有利的东西，我们全都要服从自我保存这一规律。
	但是自然规律与人为法律往往是冲突的，比如社会告诉我，不能去攻击一个恶毒的敌人，除非我是在自卫。然后自然则命令道我们应该先下手为强，这样才是最有利于自己的。面对这种冲突，安提丰提出了如下的道德方略，“因此，一个人以最有利于自己的方式行动，在城邦中受人目睹的情况下，我们应该充分地尊重城邦法律；在无人目的的情况下，我们应该尊从自然规律，这么做就是正义的。”
	
3、更激进、玩世不恭的智者
	塞拉西马柯强调了如下社会事实：那些最有权力的人制定了社会规则，所谓的正义与不正义。因此，道德仅仅是社会约定的问题，正义仅仅是服务于强者们的工具。
	卡利克勒强调了，不仅强者的权益将会生出，而且他们理应胜出，因为自然规则就是“强权即公平”
```
