## 2. 回溯

- **没错，所有的回溯法本质都是一颗树！** for循环-> 横向遍历  递归操作-->纵向遍历 , 最后加上一个剪枝操作即可！！

- 应用场景：专门解决穷举问题，回溯法不是什么高效率的方法，而是迫于无奈只能穷举

- 优化：回溯一般我们都可以使用**剪枝** ，来减少回溯次数，一般需要画图找到剪枝的地方

- 模板

  ```
  void backracking(参数){
  	if(终止条件){
  		return;
  	}
  	for(选择：本层集合中元素){   // 本层集合，一般都是当前节点的子节点的数量
  		处理节点;
  		backracking(路径，选择列表);//递归
  		回溯，撤销处理结果；
  	}
  }
  ```
