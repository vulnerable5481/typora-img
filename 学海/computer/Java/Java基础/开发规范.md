# git篇



## 1.git commit

- **<font color='red'>模版:</font>**

  - ```
    <type>[optional scope]: <description>"
    
    <body>
    
    <footer>
    ```

- **type**

  - ```bash
    - feat：新功能（feature）
    - fix：修补bug
    - docs：文档（documentation）
    - style： 格式（不影响代码运行的变动）
    - refactor：重构（即不是新增功能，也不是修改bug的代码变动）
    - perf: 性能优化
    - test：增加测试
    - chore：构建过程或辅助工具的变动
    ```

- **body**:描述详情

- **footer**：不知道干啥的

- **<font color='red'>特殊情况：恢复到之前的提交</font>**

  - ```
     Revert "feat(scope): here is a short description"
     
     This reverts commit 8bbd337eab7d54c82327159c41ac975f805e28f5.
    ```





## 2.commit文件

- 之前我都是git commit -m "message",这是不规范的
- 应该 git commit, 然后进入文本编辑器，规范你的Message
- **如何制定默认文本：在制定目录下创建或修改.gitmessage.txt,比如windows下默认是C:\Users\用户名\.gitmessage.txt**
- 注意是有个点，是隐藏文件
